# 차트명가 채널 스타일 정리

기본 프리셋(`차트명가_메인프리셋(24버전).prproj`)과 레퍼런스 영상에서 뽑아낸 값입니다.
컷씬 렌더러(`src/render/theme.js`)의 `chartmyeongga` 테마가 이 문서를 기준으로 맞춰져 있습니다.

레퍼런스 프레임은 `brand/reference/` 에 있습니다.

---

## 1. 컬러

영상 프레임에서 직접 뽑은 실측값입니다.

### 차트
| 요소 | 값 | 비고 |
|---|---|---|
| 배경 | `#FFFFFF` | **밝은 배경.** 어두운 트레이딩뷰 다크테마 아님 |
| 상승 캔들 | `#0B8C7F` | 딥 틸 |
| 하락 캔들 | `#E80001` | 선명한 빨강 |
| 이동평균선 | `#F38808` | 주황, 얇은 실선 |

### 매매 표시
| 요소 | 선 | 영역 |
|---|---|---|
| 익절 | `#14FF36` (형광 초록, 매우 굵음) | `#C5FFC4` |
| 손절 | `#9F0000` (진한 빨강, 매우 굵음) | `#F9BAC1` |
| 매수 라벨 | `#E80001` | 오른쪽을 가리키는 화살표 모양 |
| 매도 라벨 | `#0200F3` | 오른쪽을 가리키는 화살표 모양 |

익절/손절 선은 캔들보다 눈에 띄게 굵습니다. 영역은 선 사이를 옅은 색으로 채웁니다.

### 텍스트 / 배지
| 요소 | 값 |
|---|---|
| 타이틀 바 | 로즈~자주 계열 (`#8C535D` ~ `#D76D83`), 질감 있는 배경에 흰 글씨 |
| 소제목 배지 | `#8E8E8E` 회색 바탕에 흰 글씨 |
| 종목·타임프레임 배지 | `#E90054` 핑크레드 바탕에 흰 글씨 |
| 하단 자막 | 검정 박스 + 흰 굵은 글씨, 화면 하단 중앙 |
| 프레임 테두리 | 핑크 거친(찢어진) 테두리 — 인트로·광고 컷에서만 |

## 2. 화면 레이아웃

```
┌──────────────────────────────────────────────────────┐
│ [타이틀 — 고정]                              [로고]   │  ← 좌상단 / 우상단
│ [소제목#N] [종목 : 타임프레임]                        │  ← 파트마다 교체
│                                                       │
│                                                       │
│              (차트 영역 — 전체 화면)                  │
│         익절선 ══════════════════════                 │
│         ░░░░░░░ 익절 영역 ░░░░░░░░░                   │
│    ▶매수 ─────────────────────────                    │
│         ▓▓▓▓▓▓▓ 손절 영역 ▓▓▓▓▓▓▓                     │
│         손절선 ══════════════════════                 │
│                                                       │
│                  [ 하단 자막 ]                        │  ← 검정 박스
└──────────────────────────────────────────────────────┘
```

- **타이틀**: 좌상단 고정. 영상 전체에서 안 바뀜
- **소제목**: 좌상단 타이틀 아래. `#1 볼린저밴드+RSI` 처럼 파트 번호와 함께, 파트마다 교체
- **종목·타임프레임 배지**: 소제목 오른쪽에 붙음
- **로고**: 우상단, 반투명 회색
- **자막**: 하단 중앙, 검정 박스에 흰 글씨
- 차트는 축·그리드를 거의 안 쓰고 화면을 꽉 채웁니다

## 3. 폰트

`brand/fonts/` 에 들어 있습니다. 전부 무료 배포 한글 폰트입니다.

| 폰트 | 용도 추정 |
|---|---|
| Gmarket Sans (Bold/Medium/Light) | 타이틀, 강조 라벨 |
| 경기천년제목 (Bold/Medium/Light/V-Bold) | 제목류 |
| S-Core Dream (4~9) | 본문, 자막 |
| 나눔고딕 (Light/Regular/Bold/ExtraBold) | 본문, 배지 |

굵은 글씨에 **검정 외곽선(스트로크)** 을 두르는 것이 이 채널 라벨의 특징입니다.

### 저장소에 넣지 않은 것

GitHub는 파일 하나가 100MB를 넘으면 아예 거부합니다. 아래 세 개가 여기 걸립니다.

| 파일 | 크기 |
|---|---|
| `포인트_핑(차트명가).mov` | 153 MB |
| `소스_화살표(상승or하락).mov` | 128 MB |
| `원 효과(투명).mov` | 126 MB |

이것 말고도 BGM(`차트 명가 bgm.wav`, 22MB), 배경 종이질감 영상(34MB),
인트로·아웃트로·중간광고 mp4, 영트모 광고 이미지는 저장소에 넣지 않았습니다.
편집할 때만 쓰는 것이고, 컷씬 렌더러는 이것들을 코드로 다시 그리기 때문입니다.

원본 프리셋 전체(압축 422MB / 해제 765MB)는 드라이브에 그대로 두시면 됩니다.
