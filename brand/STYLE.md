기본 프리셋(`차트명가_메인프리셋(24버전).prproj`)과 레퍼런스 영상에서 뽑아낸 값입니다.

레퍼런스 프레임은 `brand/reference/` 에 있습니다.

## 2. 화면 레이아웃

```
┌──────────────────────────────────────────────────────┐
│ [타이틀 — 고정]                              [로고]   │  ← 좌상단 / 우상단
│ [소제목#N] [종목 : 타임프레임]                        │  ← 파트마다 교체
│                                                       │
│                                                       │
│              (차트 영역 — 전체 화면)                  │
│         익절선 ══════════════════════                 │
│         ░░░░░░░ 익절 영역 ░░░░░░░░░                   │
│    ▶매수 ─────────────────────────                    │
│         ▓▓▓▓▓▓▓ 손절 영역 ▓▓▓▓▓▓▓                     │
│         손절선 ══════════════════════                 │
│                                                       │
│                  [ 하단 자막 ]                        │  ← 검정 박스
└──────────────────────────────────────────────────────┘
```

- **타이틀**: 좌상단 고정. 영상 전체에서 안 바뀜
- **소제목**: 좌상단 타이틀 아래. `#1 볼린저밴드+RSI` 처럼 파트 번호와 함께, 파트마다 교체
- **종목·타임프레임 배지**: 소제목 오른쪽에 붙음
- **로고**: 우상단, 반투명 회색
- **자막**: 하단 중앙, 검정 박스에 흰 글씨
- 차트는 축·그리드를 거의 안 쓰고 화면을 꽉 채웁니다

### 격자박스 — 세 요소가 앉는 자리

**영상**은 `brand/EDIT-RULEBOOK.md` ⑮ 세이프 에어리어가 원본입니다. 요약하면
좌상단 타이틀 가로 35%×세로 20%, 우상단 로고 가로 12%×세로 20%, 자막 세로 15%,
콘텐츠 존 `y 216~918`. 숫자는 룰북을 보세요 — 여기 옮겨 적으면 두 곳이 어긋납니다.

**썸네일**은 상자가 다릅니다. 타이틀이 화면을 훨씬 크게 먹는 매체라서요.
좌상단 타이틀 상자는 `(75,100)~(1306,394)`, 구현은 `tools/photoshop/config.json` 의
`titleBox` 입니다 (thumbnail_rule 28·29).

두 매체가 공유하는 것은 숫자가 아니라 방식입니다 — **글자 크기를 회차마다 손으로
정하지 말고, 상자를 먼저 정하고 거기에 맞춥니다.**

### 저장소에 넣지 않은 것

GitHub는 파일 하나가 100MB를 넘으면 아예 거부합니다. 아래 세 개가 여기 걸립니다.

| 파일 | 크기 |
|---|---|
| `포인트_핑(차트명가).mov` | 153 MB |
| `소스_화살표(상승or하락).mov` | 128 MB |
| `원 효과(투명).mov` | 126 MB |

이것 말고도 BGM(`차트 명가 bgm.wav`, 22MB), 배경 종이질감 영상(34MB),
인트로·아웃트로·중간광고 mp4, 영트모 광고 이미지는 저장소에 넣지 않았습니다.
편집할 때만 쓰는 것이고, 컷씬 렌더러는 이것들을 코드로 다시 그리기 때문입니다.

원본 프리셋 전체(압축 422MB / 해제 765MB)는 드라이브에 그대로 두시면 됩니다.

## 5. 최종본에서 확인한 추가 디테일

`02_차트명가(최종본)` 폴더의 롱폼·숏츠 최종본을 프레임 단위로 뜯어본 결과입니다.
템플릿 프로젝트와 최종본이 조금 다른데, **최종본 쪽이 실제 채널 룩**입니다.

### 매수 / 매도 태그

| 항목 | 값 |
|---|---|
| 크기 | 1080p 기준 가로 약 116px, 세로 약 48px (**작다**) |
| 모양 | 오른쪽을 가리키는 화살표. 머리 삼각형이 길고 뾰족함 |
| 색 | 매수 빨강 / 매도 파랑 |
| 글씨 | 흰색, **검정 외곽선 없음** |
| 테두리 | 검정 대신 **얇은 흰 여백(헤일로)** 만 |

템플릿 프로젝트의 태그에는 검정 외곽선이 있지만 최종본에는 없습니다.

### 익절 / 손절 표기 — 기본 프리셋 기준 (1920x1080 실측)

| 항목 | 값 |
|---|---|
| 익절 선 | `#14FF35`, 두께 **23px** |
| 손절 선 | `#9F0000`, 두께 **23px** |
| 익절 영역 | `#BAFDC0` |
| 손절 영역 | `#FEBABA` |
| 라벨 박스 | 선과 같은 색, **각진 사각형 173 x 84px** |
| 라벨 글씨 | 흰색, **검정 외곽선 없음**, 약 62px |
| 라벨 위치 | 선이 시작하는 지점의 **왼쪽에 딱 붙임**, 세로는 선 중심에 맞춤 |
| 영역 시작점 | 진입 캔들부터. 그 왼쪽은 비워 둠 |

> 최종본 영상 중에는 라벨을 영역 한가운데에 큰 흰 글씨(얇은 검정 외곽선)로
> 쓴 것도 있지만, 그건 그 영상만의 변형입니다. **기본은 위 표의 컬러 박스**입니다.
> 렌더러에서 변형이 필요하면 `labelStyle: 'inzone'` 으로 바꿀 수 있습니다.

### 강조 표시

- **손그림 빨간 마크** — 원, 밑줄, X. 색연필 질감. 강조할 때 반복해서 쓰임 (`#C0272D` 계열)
- **번호 배지** — `①박스권 확인` 처럼 짙은 자주 알약, 흰 글씨, 검정 테두리 없음
- **아웃트로 한줄평** — 차트를 회색으로 딤 처리하고 핑크 띠 + 큰 흰 글씨

### 그 밖에

- 최종본 롱폼 출력은 **1280×720 / 30fps** (컷씬 소스는 1080p 로 넘겨도 무방)
- 캔들 색은 영상마다 다름 — TradingView 계열은 청록/빨강, 국내 플랫폼 화면은 빨강/파랑
- 차트에 축·그리드를 쓰지 않고 화면을 꽉 채움

### 스크립트 구조 (`[차XX_기본폼]_롱폼 기획서+스크립트`)

1. 후킹(현황&썰) → 2. 소개 → 3. 본론#1(대제목) → 4. 문제 제시
→ 5. 본론#2(메인, 전략 1·2) → 6. 아웃트로(CTA)

컷씬은 이 여섯 단계 중 어디에 붙는지에 따라 톤이 달라집니다.
지금 작업한 4컷은 **4. 문제 제시** 구간입니다.
