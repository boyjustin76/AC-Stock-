## 3. 차트 화면 문법 (전 회차 공통)

- **배경 흰색, 축·눈금·그리드 없음, 풀블리드.** 차트는 스크린샷(정지 이미지)이고
  회차당 중앙값 4장(min 0, max 30 — #1 특례). 스토리 진행은 "나중 시점 스크린샷"으로 디졸브.
- **캔들 색은 회차별 플랫폼 색**: 청록/빨강(#1 레인보우·#3~#10, 브랜드 실측 #0B8C7F/#E80001) 또는
  **빨강/파랑(#1 EMA챕터·#2)**. 심지 1px, 몸통 테두리 없음(플랫폼 그대로).
- **이평선: 굵고(5~8px) 매끈한 실선이 캔들 위를 지난다.**
  #2(이평선+RSI — 차12의 직접 선례): **10일선=빨강, 35일선=주황**. 초록 이평선은 #2 문법에 없다
  (#10 프랙탈 챕터의 20일선만 형광 초록). → **차12는 #2 배색을 따른다: 빨강(10)/주황(34).**
- **RSI 서브패널**: 흰 배경 + 얇은 파랑 라인. 경계 표기는 두 유파 —
  #2: 위 헤어라인 구분 + **회색 점선 55/45**; #9: **진한 파랑 실선 4변 프레임 + 좌상단 'RSI' 라벨 칩**.
  (#8 스토캐스틱도 색깔 프레임+라벨 칩.) → 차12는 프레임+라벨 칩+점선 55/45 를 조합(둘 다 정본).
- 실제 **HTS/플랫폼 설정창 스크린샷**을 그대로 화면에 띄우고 빨간 사각으로 강조 (#2·#3·#5·#9).

## 4. 오버레이 어휘 (전 회차 채록 — 이것으로만 조립한다)

**앵커/라벨**
1. 지표 색박스 라벨 — 지표 색과 같은 색 사각 박스+흰 글씨 (`10SMA`·`35SMA`·`100일선`·`5일선`…), 설명 텍스트는 검정.
2. 핑크 알약 배지 — `①이동평균선: 골든크로스` `②RSI: 눌림목 구간` `③조건 충족` (누적 스토리텔링, #2·#9).
3. 매수/매도/익절/손절 **화살표 태그** — 매수 빨강/매도 파랑, 작게(116×48), 흰 글씨·흰 헤일로.
   #10 변주: 계약수 알약 `매수(0.1)` 빨강 / `매도(0.2)` 파랑.
4. 검/파 사각 라벨(`단기조정`/`추세전환`, #1), `손실 중` 검정 라벨(#10), 번호 마커 1~5(#2·#5), ①②③④ 윤곽 숫자(#6).

**존/영역**
5. 손절 = 굵은 빨간 선(23px)+연분홍 반투명 존+`손절` 라벨 / 익절 = 굵은 초록 선+연초록 존+`익절 2` 라벨.
   진입 캔들부터 오른쪽으로. (#2 연한 톤 ↔ #9 쨍한 초록 — 둘 다 정본.)

7. 박스권/채널 = 검은 선 #111111 (#1·#6 검은 채널 2선), 빨간 굵은 저항선+`저항선` 빨간 박스 라벨(#6),
   초록 지지선(#5), 피보나치 초록 수평선+`38.2`/`61.8` 라벨(#6).

**강조**

## 5. 차12 재작에의 적용 (r13 조립 규칙)

- 컷 안에서 차트는 **1장 고정** (렌더러: reveal 숫자). 스토리 진행은 phases 디졸브(30f)로
  "나중 시점 스틸" 교체 — §0·§1 문법의 엔진 등가물.
- 등장은 §2 의 4종 + 30f 디졸브만. 드로우온(그려지는 선)은 손그림 낙서류(§4-10)에만 허용
  (실영상의 원 효과.mov 등가). 카메라 모션·줌·팬·리빌 **금지** (§2 부재 증거).
- 차트 배색은 #2 상속: 캔들 빨강/파랑, 10일선 빨강·34일선 주황, RSI 파랑 + 프레임/라벨 칩 + 55/45 점선.
- 진짜 캔들: 실 NQ 시세 (`data/nq/`) 주입 — 합성 캔들 폐기.
- 렌더 제외(프리미어 몫)는 종전과 동일: 타이틀/소제목/배지/로고/자막. 챕터 카드도 프리셋 몫.
