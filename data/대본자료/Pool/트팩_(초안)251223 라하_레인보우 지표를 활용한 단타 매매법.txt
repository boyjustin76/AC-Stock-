1️⃣ 도입부: 문제 정의: 우리가 단타를 어려워 하는 이유는 뭘까요?
단타 매매에서 가장 흔한 실수 제시
화살표·신호 발생 즉시 진입
그로 인해 발생하는 문제 정리
손절 기준 혼란
추세와 무관한 진입
영상의 목적 명확화

2️⃣ 지표 전체 구조 소개
본 매매법이 2가지 보조지표의 결합 구조임을 설명
레인보우 지표
화살표 지표(TF 시그널에서 있는)
: 간단한 설치 방법 소개설치방법은 간단합니다. 아래 링크를 통해 레인보우 차트를 클릭 후받으신 파일을 클릭해주시면 자동으로 설치가 됩니다.이제 메타트레이더5에서 탐색기를 확인해보시면 레인보우mma라는 버튼이 있으실것입니다. 그리고 영트모 회원분들에게 제공해드린 tf 시그널의 파워차트의 sig만 단독적으로 클릭하시면 바로 사용하실 수 있습니다.
각 지표의 역할을 간단히 말씀드리자면
레인보우 지표로는 추세 방향·강도 판단
화살표로는 추세 안에서의 진입 후보 위치 표시
그리고 반드시 2가지를 함께 사용해주셔야 하며 “단독 사용 불가” 합니다
3️⃣ 레인보우 지표 설명 (핵심 필터)
3-1. 레인보우 지표의 기본 개념
다중 이동평균선 구조 설명
배열 상태가 의미하는 것 정리
3-2. 레인보우 상태별 해석
정배열 → 상승 추세
역배열 → 하락 추세
꼬임/밀집 → 박스권 또는 추세 부재
3-3. 레인보우 지표의 역할 한정
“진입 신호 아님”
방향과 환경 판단용 필터임을 강조
4️⃣ 화살표 지표 설명 (보조 신호)
화살표의 의미 정의
매수·매도 ‘신호’가 아닌 ‘참고 위치’
화살표 단독 사용 시 발생하는 오류 설명
반드시 레인보우 방향과 결합해야 하는 이유 제시
5️⃣ 두 지표를 결합하는 해석 순서
해석의 고정 순서 제시
레인보우로 추세 확인
추세 방향 결정 (롱 or 숏 or 관망)
해당 방향의 화살표만 확인
추세와 반대되는 화살표는 의미 없음을 명확히 설명
6️⃣ 핵심 필터: 레인보우 훼손 여부
화살표가 떠도 진입하지 않는 대표적 상황 설명

추세 약화

“겉보기 정배열”과 “실제 추세”의 차이 설명
7️⃣ 진입 타이밍 규칙
