🎬 인트로 및 RSI 주제 소개 (= RSI 지표란?)
슬라이드 제목: RSI란 무엇인가?
정의:RSI(Relative Strength Index, 상대강도지수)는 일정 기간의 상승폭과 하락폭의 비율을 분석하여 가격의 강도(모멘텀)를 수치화한 보조지표
기본 설정: 14일 기준, 0~100 사이의 값
📌 해석 기준:
RSI > 70: 과매수 (매도 경계)
RSI < 30: 과매도 (매수 경계)
RSI ≈ 50: 중립 → 기준선으로 활용
⚙️ 간단한 설치 방법 (메타트레이더5 기준)
슬라이드 제목: RSI 지표 설정 (MT5 기준)
메타트레이더5 차트 상단 메뉴 → “삽입” 클릭
“지표” > “오실레이터” > “Relative Strength Index” 선택
기간 설정: 14, 레벨: 30 / 50 / 70
📌 팁: 레벨 50을 기준선으로 추가하면 추세 분석에 유리
❗ 과매수/과매도 구간만 보고 진입한다? (단순 활용의 위험성 강조)
슬라이드 제목: 단순 RSI 활용, 왜 위험한가?
오해: RSI 70 이상이면 무조건 매도 / 30 이하면 무조건 매수?
현실: 강한 추세에서는 RSI 70 이상에서도 상승 지속, RSI 30 이하에서도 하락 지속 가능
✅ 해결책: 추세 확인 + 캔들/거래량 + 보조지표 조합 필요
💡 RSI 실전 매매기법 시리즈
① RSI 추세선 매매법 전략
개념 :RSI는 고점과 저점으로 꺾이는 구조를 가지므로, RSI 값 자체에 추세선을 그려 매매 타점을 포착하는 방법
전략 :RSI의 저점과 저점을 연결해 추세선을 설정한 후,RSI가 이 추세선을 돌파 → 눌림 → 재진입하는 지점을 매수 타점
📌 매매 포인트 구성
항목
내용
✅진입 타점
RSI가 추세선을 돌파한 후 눌림이 발생하고, RSI가 다시 재진입하는 시점
❌손절 기준
RSI가 추세선 아래로 다시 이탈할 경우, 또는 RSI 재진입 실패 시
💰청산 타점
RSI가 과매수 구간(예: 70 이상) 도달하거나, 가격이 목표 수익률 도달 시
📊 매매법의 장단점
장점
단점
- 눌림목 진입으로 유리한 가격 확보
- RSI 추세선은 주관적 해석 여지 큼
- 빠른 매수 시그널 포착 가능
- RSI만 단독 사용 시 노이즈 발생 가능
② 기준선(50) 돌파 전략
개념 :RSI가 50선을 돌파하면 강세·약세 전환을 나타내며, 추세 시작을 알리는 중요한 매매 신호
전략 :
RSI 50 상향 돌파 + 양봉 캔들 → 매수
RSI 50 하향 돌파 + 음봉 캔들 → 매도

❌손절 기준
돌파 직전 캔들의 저점/고점 이탈

- 신호 기준이 명확해 초보자도 사용 용이
- 캔들 종가 판단 필요로 타이밍 지연 우려
③ 다이버전스 전략
*다이버전스란?
다이버전스(Divergence)는 가격의 흐름과 보조지표(RSI, MACD 등)의 흐름이 반대로 움직이는 현상
개념 :가격과 RSI 흐름이 반대로 움직일 때 → 추세 전환 가능성이 높고, 탈진 구간 포착에 유효
전략 :
상승 다이버전스:가격: 저점 하락 / RSI: 저점 상승 → 매수 신호
하락 다이버전스:가격: 고점 상승 / RSI: 고점 하락 → 매도 신호
📌 매매 포인트 구성
항목
내용
✅진입 타점
다이버전스 발생 후 RSI 반전 확인 시
❌손절 기준
다이버전스 무효화(=전저점/전고점 갱신)
💰청산 타점
RSI 50 돌파 or 이전 지지/저항선
📊 매매법의 장단점
장점
단점
- 추세 전환 포착에 효과적
- 다이버전스의 타이밍 지연 가능성
- 탈진 신호로 위험 회피 가능
- 거짓 신호 발생 빈도 높음 (보조 확인 지표 필요)
④ 페일리어 스윙 전략 (Failure Swing)
개념 :RSI가 70/30 돌파 후 되돌림 없이 않고 고점/저점을 갱신하지 못할 때(실패시)
→ 추세 반전 신호로 해석
전략 :
RSI 70 이상 돌파 실패 + 꺾임 → 매도
RSI 30 이하 돌파 실패 + 반등 → 매수
추세 반전 확정 구간 포착 전략

- RSI 단독 해석 시 신뢰도 낮아질 수 있음
⑤ 더블 RSI 전략
개념 :단기 RSI로 진입 타이밍 포착,장기 RSI로 추세 유효성 필터링
전략 :
단기 RSI가 장기 RSI를 상향 돌파 → 매수
단기 RSI가 장기 RSI를 하향 돌파 → 매도
민감성과 안정성을 함께 확보한 전략

⑥ RSI+볼린저밴드
개념 :RSI의 과매도/과매수 구간에서의 반전 신호와, 볼린저밴드의 하단(또는 상단) 접촉을 함께 활용하여 되돌림 구간 진입을 노리는 전략
전략 :
RSI가 과매도(30 이하) 구간에서 반등 시도 + 볼린저밴드 하단선 터치 또는 이탈 후 재돌파 시 매수
반대로 RSI 과매수(70 이상) + 상단선 접근 시 매도 가능

✅ 흔한 실수와 오해들
예상
현실
RSI 70이면 무조건 매도, 30이면 무조건 매수한다
강한 추세에서는 RSI 70 이상에서도 계속 상승, 30 이하에서도 계속 하락 가능
과매수는 고점, 과매도는 저점이다
과매수·과매도는 '과열된 상태'이지 반전 확정 신호는 아님
모든 종목에 RSI 14일이 정답이다
단기 트레이딩, 급등주, 비트코인 등에서는 민감도 조절 필요
RSI는 단독으로도 충분하다
RSI는 모멘텀 지표일 뿐, 추세 방향은 알 수 없음
다이버전스는 항상 반전의 신호다
약한 다이버전스는 반전이 아닌 조정 후 재추세 강화로 이어질 수 있음
RSI 50은 무시해도 되는 수치다
RSI 50은 추세 중립선으로, 돌파 여부가 추세 전환의 핵심 신호가 됨
