## 자료를 다시 뜨는 법

전부 원본이 이 PC 에 있어서 언제든 다시 만들 수 있다. 원본이 진짜고 여기 있는 건 사본이다.

```bash
python 도구/pool.py        # G:\…\05_문서_기획+스크립트(아카이브) + 저장소 scripts.json → Pool/
python 도구/majors.py      # 유튜브 자막 받아 메이저자막/ (yt-dlp · YOUTUBE_API_KEY)
python 도구/corpus.py      # 채널별 자막 정리·수치
```

재는 도구는 자료만 있으면 바로 돈다 (2026-09-18 일곱 개 전부 돌려 확인):

```bash
python 도구/tri.py         # 회사 Pool vs 메이저 — 분량·문장·과장·근거·수치 P25/중앙/P75
python 도구/styleAB.py     # 회사 '전문가 형' vs '인플루 형' 실측 대조
python 도구/style_scan.py  # 채널별 문체 수치
python 도구/skeleton.py    # 차명 Old 대본의 구간 틀
python 도구/skeleton2.py   # 더원 촬영용 대본의 구간·분량 비율 (규격의 출처)
python 도구/l07_survey.py  # 더원 L01~L09 한 줄 요약표
python 도구/tri2.py        # 우리 '실제 발화'(자막) vs 메이저 발화
```

`pool.py` 는 **구글 드라이브 데스크톱이 켜져 G: 가 붙어 있어야** 돈다.

## 이 자료를 뜨면서 밟은 함정 (같은 데 또 밟지 말 것)

- **이름이 같은 원고가 폴더 세 곳에 있다** (`[스타일A_전문가 형]000` 등). 2026-09-18 이전 `pool.py` 는
  뒤에 읽은 것이 앞을 **조용히 덮어썼다** — 목록은 181편인데 디스크에는 168개뿐이었다.
  지금은 내용이 같으면 한 번만 쓰고 다르면 `_2` 를 붙인다. **그래서 편수가 181 → 173 으로 줄었다**
  (없어진 게 아니라 같은 것을 두 번 세던 것을 그만둔 것).
- 윈도우는 **이름 끝의 공백·마침표**를 조용히 떼거나 폴더를 못 열게 만든다. 이름을 지을 때 `.strip(" .")`.
- `index.json` 의 `src` 칸에 **원본이 드라이브 어디서 왔는지**가 적혀 있다. 원천을 거슬러 올라갈 때 쓴다.
