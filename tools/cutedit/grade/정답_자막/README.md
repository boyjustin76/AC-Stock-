# 정답 자막 — 사람이 손으로 나눈 것

자막 큐를 **어디서 끊을지**는 규칙으로 정할 수 없다. 사람 수정본이 정답지다.
여기 있는 파일로 `ko_clause` 의 값을 맞춘다.

| 파일 | 무엇 | 쓸 때 |
|---|---|---|
| `마01_캠_이정찬_손수정본.txt` | **이정찬이 손으로 나눈 자막 99줄** (2026-10-01, 마이노 마01 캠 롱폼). 대본 2007자 가운데 앞 1186자(56%)까지. 뒤는 "힘들어서" 안 하셨다 | `../가름대조.py` · `../가름값맞추기.py` |

## 이 자료에서 읽어낸 이정찬 습관 (2026-10-01 실측)

평균 **12.0자**. 경계 99개를 뜯어 보면:

1. **구두점 뒤는 반드시 끊는다.** 쉼표·마침표 뒤를 안 끊은 자리가 **하나도 없었다.**
   그래서 `ko_clause` 는 그 자리에 벌점이 아니라 **상(−6)** 을 준다.
2. **관형절 끝에서 자주 끊는다** — `접촉했다는 | 단일 사실`, `회귀하는 | 20일 중심선`,
   `하나가 아닌 | 두 개를`, `수치로 알려 주는 | 하나의 기준선일`.
   처음엔 '관형형과 꾸밈받는 말을 떼면 안 된다' 고 **아예 막아 뒀는데 그게 틀렸다.**
   관형절은 절 경계다. 허용하되 구두점보다 비싸게 둔다(2점).
3. **`-아/어/여` 뒤도 끊는다** — `닿아 | 매수했음에도`, `즉각 청산하여 | 수익을`.
4. **주어 뒤도 끊는다** — `20일 중심선이 | 우상향이면`.
5. 반대로 **붙여 두는 것**: 보조용언(`알려 주는`) · 의존명사(`두 개를`) ·
   복합명사(`손절 폭이`) · 따옴표 안(`'더블 볼린저 밴드'`) · `-의` 뒤(`신호 캔들의 최저점`) ·
   앞말 없이 못 서는 용언(`매수했음에도 불구하고`, `메인 밴드에 비해`).

```
줄 174개 · 평균 12.1자   (이정찬 99줄 · 평균 12.0자)
```

일치율만 보면 안 된다 — 끊는 자리를 늘리면 우연히 맞는 것도 늘어난다. **재현과 정밀을 같이 본다.**
