# 채점대 — 규칙은 정답 자료에 대고 고른다

컷편집 규칙을 감으로 바꾸지 않기 위한 채점 도구다. **정답은 이정찬이 손으로 고친 숏폼 두 편**
(S015·S016)이고, 자료를 저장소 안에 같이 둔다 — 임시폴더에만 있으면 세션이 끝날 때 사라져서
규칙을 다시 잴 수가 없다.

```
grade/
  paths.py     자료 위치 (환경변수 CUTEDIT_GRADE_WORK · CUTEDIT_GRADE_TRUTH 로 딴 데 지정 가능)
  truth/       정답 — <회차>_수정.srt · <회차>_컷편집_수정.xml (이정찬 수정본 그대로 복사)
  work/s015    STT·정렬 결과 (aligned.json · cam_transcript.json · silences*.txt · cuts.json · verified.json)
  work/s016    같음.  ※ 원본 영상과 .wav 는 저장소에 두지 않는다 (용량) — 드라이브·로컬에 있다
```

| 도구 | 무엇을 재나 | 지금 값 (2026-09-16 재확인) |
|---|---|---|
| `python tune.py --current` | 컷 경계 50개를 사람 손과 견준다 | **평균 0.051초** · 최대 0.28초 |
| `python tune.py` | 문턱·핸들 값 540가지 격자 탐색 | 지금 값이 최상위권(0.0573 무리) |
| `python cuetune.py` | 자막 끊는 자리가 사람과 겹치는가 | **끊는자리 35/53** · 문장 49개 중 34개 똑같이 |
| `python tgrade.py` | 자막 큐 시작 시각 오차 | **글자수 비례 0.279초** vs 낱말 시각 0.315초 → 비례 채택 |

숫자를 바꾸는 제안은 여기서 먼저 재고, 나빠지면 버린다. 버린 것들도 근거와 함께
`tools/theone/README.md` 「바꾸거나 새로 잰 것」 표에 남겼다.

**주의** — `tune.py` 는 `cut_and_srt.build_cuts` 를 파라미터로 흉내 낸 것이다. 본 도구를 고치면
이쪽도 같이 고쳐야 같은 것을 재게 된다.
