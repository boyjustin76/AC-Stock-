# 차트 리플레이 사용법 — 한 장

촬영 중에 **직접 차트를 감으면서** 설명하시면 됩니다. 편집에서 따로 만들 것이 없어집니다.

## 손가락 다섯 개만 기억하시면 됩니다

| 키 | 하는 일 |
|---|---|
| **X** | 한 봉 **앞으로** (다음 봉이 생깁니다) |
| **Z** | 한 봉 **뒤로** |
| **S** / **A** | 열 봉 앞으로 / 뒤로 |
| **스페이스** | 자동 재생 / 멈춤 |
| **N** / **B** | **다음 장면** / 이전 장면 (큐시트 순서대로 종목·주기·시각이 한 번에 바뀝니다) |
| **H** | 조작판 숨기기 / 보이기 |
| **R** | 지금 시각까지 **자료 다시 받기** (붙인 뒤에 생긴 봉을 가져옵니다) |

> 키는 **차트를 한 번 클릭해 두고** 눌러야 먹습니다. 화살표 키는 MT5 가 화면 이동에 쓰므로 안 씁니다.

## 화면이 이렇게 됩니다

- 바탕은 흰색, 이동평균선은 **5(주황) · 20(파랑) · 60(보라) · 120(회청)** 입니다.
- 오른쪽은 **비어 있습니다.** 아직 오지 않은 미래가 가려진 것입니다.
  X 를 누르면 그만큼 채워지고, Z 를 누르면 그만큼 더 가려집니다.
  **화면은 움직이지 않습니다** — 가리개만 좌우로 갑니다. (한쪽 끝에 닿으면 그때 한 번 가운데로 잡습니다.)
- 지표(이동평균선)도 **같이 되감깁니다.** 미래를 보고 그린 선이 아닙니다.
- 봉은 항상 **다 만들어진 상태**로 끊깁니다. 중간에 걸친 봉이 보이지 않습니다.

## 시작할 때

1. MT5 를 켜고, 쓸 종목 차트를 엽니다 (예: `US100.` 2분봉).
2. 탐색기 > **시스템트레이딩 > Replay_Tool_CMG** 를 그 차트에 **끌어다 놓습니다.**
   → 잠시 뒤 **`<종목>_REPLAY` 차트가 저절로 열리고** 거기에 조작판이 뜹니다. 원래 차트는 그대로 돌아갑니다.
   (한 번 더 끌어다 놓을 필요 없습니다. 자료를 받느라 10~30초 걸릴 수 있습니다.)
3. **N** 을 누릅니다 → 큐시트의 첫 장면으로 갑니다. 그 뒤로는 N 으로 넘기며 찍으면 됩니다.

## 잘 안 될 때

| 증상 | 이렇게 하세요 |
|---|---|
| 키가 안 먹는다 | 차트 아무 데나 한 번 클릭하고 다시 누릅니다 |
| 오른쪽이 안 비어 있다 | H 로 조작판을 켜고 RESET 을 누릅니다 |
| 화면이 자꾸 따라 움직인다 | EA 설정에서 `InpMaskFuture` 가 **true** 인지 보세요. false 면 옛 방식이라 절반에서 화면이 따라옵니다 |
| 다른 종목으로 안 넘어간다 | 처음 넘어갈 때 자료를 받느라 **10~30초** 걸립니다. 기다리시면 됩니다 |
| 최근 봉이 없다 (몇 시간 전까지만 있다) | **R** 을 누릅니다. 그래도 그대로면 MT5 자체가 그 종목의 1분봉을 거기까지만 갖고 있는 것입니다 — 원본 종목 차트를 1분봉으로 열어 두면 채워집니다 |
| 화면이 멈춘 것 같다 | 자료를 받는 중입니다. 왼쪽 위 조작판(H)의 Status 줄을 보세요 |

## 만드는 쪽(편집자)이 할 일

```bash
# 큐시트를 만들면 MQL5\Files\cmg_cues.csv 까지 자동으로 들어간다
python tools/mt5/cue_sheet.py <콘티폴더> --title 차11

# 촬영용 차트 템플릿 (흰 바탕·이평선 4개·오른쪽 여백 50%)
python tools/mt5/make_template.py          # → MQL5\Profiles\Templates\CMG_촬영.tpl
```

차트에 템플릿을 씌운 뒤 EA 를 다시 붙입니다. 촬영용 설정은
`InpHidePanel=true`(조작판 숨김) · `InpChartScale=4`(봉 굵기) · `InpShiftPercent=50`(오른쪽 여백) 입니다.

리플레이가 지금 어디에 서 있는지는 `MQL5\Files\cmg_replay_<차트ID>.txt` 에 계속 적힙니다
(끝 봉 시각·종가·화면 위치). 눈으로 보지 않고 확인할 때 씁니다.
