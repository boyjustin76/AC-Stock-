# tools/theone — 더원트레이더 시리즈 전용

**이 폴더는 차트명가가 아니다.** 저장소의 나머지(`tools/shortform.py`,
`tools/cutedit/`, `log/SCRIPT-LAB.md`, `brand/`)는 전부 **차트명가** 기준이다.
여기 있는 것만 **더원트레이더** 자료를 다룬다. 규칙·수치를 서로 옮겨 쓰지 말 것.

| | 차트명가 (숏폼) | 더원트레이더 (숏폼) |
|---|---|---|
| 회차 이름 | `YYMMDD_[SL_차XX_#N]제목` | `SNNN_제목_YYMMDD` |
| 자료 위치 | `03_영상_소스_숏츠/차트명가(숏)` | `더원트레이더_JG/숏폼_프로젝트모음` |
| 대본 뼈대 | 훅·본문·CTA (`tools/shortform.py`) | ①훅 ②근거 ③본론 ④결론 |
| 초당 글자수 | 6.72~6.91자 (실측) | **5.43~5.91자** (자막 6편 실측) |
| 본편 길이 | 중앙값 55.9초 | 39~83초 |
| 규칙 문서 | `log/SCRIPT-LAB.md` | 없음 (아직 실측만) |

**초당 글자수가 1자 넘게 다르다.** 차트명가 기준으로 더원트레이더 대본 분량을
잡으면 20% 가까이 어긋난다.

## 도구

```bash
# 대본 인덱스 만들기
python3 tools/theone/srt_index.py <자막폴더> --out 인덱스.md --json 인덱스.json

# 어떤 회차의 레퍼런스 후보를 다른 편에서 찾기
python3 tools/theone/srt_index.py <자막폴더> --ref S012

# 낱말이 나오는 자리를 타임코드로 찾기
python3 tools/theone/srt_index.py <자막폴더> --find 눌림목 역추세
```

```bash
# 최종본에서 참고스틸 뽑기 / 여러 시각을 한 장으로 훑기
python3 tools/theone/stills.py sheet <영상.mp4> <결과.png> 3 12 22 35 42 52
python3 tools/theone/stills.py grab  <영상.mp4> <폴더> S008 36 라벨_추세추종매매
```

`srt_index.py` 는 자막 큐를 말 덩어리로 다시 묶고, 본 나레이션 뒤에 붙은
라이브·현장 설명 구간을 따로 갈라 준다 (S006·S007 에 그런 구간이 있다).

## 카피맵을 쓸 때 반드시 확인할 것

1. **자막 타임코드 = 최종본 타임코드인가.** 더원트레이더 숏폼은 같았다 —
   최종본이 4.5~5.9초 긴 것은 뒤에 아웃트로가 붙어서다. 프레임을 뽑아
   자막 문구와 대조해 확인한 뒤에 쓴다.
2. **자막에는 있는데 최종본에 없는 구간이 있다.** S006 은 04;01 뒤,
   S007 은 01;12 뒤가 편집에서 빠졌다(최종본 88.2초 · 79.0초).
   그 구간은 연출 복붙 대상이 아니다 — 멘트·촬영 참고로만 쓴다.
3. **연출은 자막으로 못 고른다.** 화면을 봐야 한다. `stills.py sheet` 로
   훑고, 고른 자리를 `grab` 으로 뽑아 카피맵에 파일명으로 건다.

## 컷편집은 공용이다

`tools/cutedit/` (STT → 정렬 → 컷 → 자막 → 시퀀스 XML) 는 두 시리즈에 다 쓴다.
S015·S016 이 더원트레이더 회차였고 거기서 경계 규칙을 실측했다.
