# 상단 배너 로직 — 임베딩으로 다시 (KURE-v1)

> 앞 문서(`상단배너_로직.md`)는 제가 눈으로 보고 규칙을 세운 것이다.
> 이번엔 **쌍 데이터를 만들어 수치로** 쟀다. 방법은 총괄 Fable 제안을 따랐다.

## 방법

| 단계 | 한 것 |
|---|---|
| 쌍 만들기 | `.prproj` 텍스트 레이어 + 같은 회차 `.srt` → **쌍 53개** (`tools/theone/pairs.py`) |
| 재는 자 | **KURE-v1** (고려대 NLP · 한국어 검색 벤치 1위 · bge-m3 미세조정 · 1024차원) |
| 서랍 | **Chroma** 로컬 저장 → `_chroma/` (collection `theone_banner`) |

**교차검증** — 최종본 mp4 프레임에서 눈으로 읽은 배너 12개와,
`.prproj` 안 텍스트 레이어가 **6/6 일치**했다. 배너 실측은 틀리지 않았다.

쌍 53개 = 배너 24(윗줄12·아랫줄12) + 화면라벨 29(`지지선`·`매수 준비`·`관망`·
`기간:20 데비에이션 2.0`…). 이 중 대본이 붙는 것 41개, 대본 있는 회차 6편.

> 낱말 하나만 넣으면 이 모델도 변별이 약하다(사과–과일 0.52 / 사과–자동차 0.47).
> 커뮤니티 경고 그대로 **맥락이 있는 문장**으로 넣어야 한다. 그래서 대본은 문장
> 덩어리로, 배너는 줄 단위로 넣었다.

## 잰 것

### ① 아랫줄이 대본 '전체'에 더 가깝다

| 회차 | 윗줄↔대본 | 아랫줄↔대본 | |
|---|---|---|---|
| S006 | 0.403 | **0.496** | 세 가지만 기억하세요! / 이평선 개념정리 |
| S007 | 0.410 | **0.549** | 아직도 그냥 쓰세요?! / 볼린저밴드의 변신 |
| S008 | **0.627** | 0.588 | 추세추종? 역추세? / 손실 최소화 매매법 |
| S009 | **0.685** | 0.499 | 나만의 원칙 만들기 / W.H.W 매매기준 |
| S011 | 0.444 | **0.579** | 세 가지만 기억하세요! / RSI? 쉽다 쉬워 |
| S012 | 0.431 | **0.592** | 세 가지만 기억하세요! / 20일 이평선 |
| 평균 | 0.500 | **0.550** | |

아랫줄이 +0.051 더 가깝다. **예외 둘(S008·S009)은 윗줄이 곧 주제인 편이다** —
`추세추종? 역추세?`, `나만의 원칙 만들기`. 그때는 아랫줄이 부제로 밀린다.
→ **주제는 두 줄 중 한 곳에만 놓는다.** (앞 문서에서 '개수는 한 곳에만'이라 쓴 것의
   더 일반적인 형태다.)

### ② 배너는 대본 어디에서 나오나

가장 가까운 대본 대목을 찾으면 —

- **아랫줄: 6편 중 4편이 대본 앞머리(훅)** — S007 0.609 · S009 0.589 · S011 0.693 ·
  S012 0.752. 훅에 주제어가 나오니 당연하다.
- **윗줄: 앞(3편) 아니면 뒤(3편).** 뒤에서 온 셋은 전부 마무리 문장이다 —
  S011 ← "꼭 기억해두세요", S012 ← "기억할 것은 세 가지입니다".

→ **아랫줄은 훅에서, 윗줄은 훅 아니면 마무리에서 가져온다.** 중간 본문은 안 쓴다.

### ③ 압축률이 아니라 '절대 글자 수'가 규격이다

| 회차 | 대본 | 윗줄 | 아랫줄 |
|---|---|---|---|
| S006 | 532자 | 12 | 8 |
| S007 | 777자 | 12 | 9 |
| S008 | 437자 | 10 | 10 |
| S009 | 224자 | 10 | 10 |
| S011 | 415자 | 12 | 10 |
| S012 | 373자 | 12 | 7 |

대본이 224자든 777자든(3.5배 차이) 배너는 **윗줄 10~12자·아랫줄 7~10자**로 같다.
압축비는 1/22~1/86으로 들쭉날쭉하다. **분량에 비례해 줄이는 게 아니라 칸이 정해져 있다.**

### ④ 낱말 보존 — 윗줄 36% · 아랫줄 50%

아랫줄이 대본 낱말을 그대로 더 많이 쓴다. 윗줄은 새로 쓰는 비중이 크다.

### ⑤ 새로 안 것 — **아랫줄에는 상한이 있다**

아랫줄↔대본 유사도가 **0.496~0.592 (평균 0.550, 편차 0.040)** 로 아주 좁은 띠를 이룬다.
윗줄은 0.403~0.685 (편차 0.112) 로 두 배 넓다.

이걸로 후보를 채점해 보면 갈린다 —

| 후보 | 점수 | 판정 |
|---|---|---|
| 구름대만 남기세요 | 0.558 | ○ 평균에 가장 가깝다 |
| 구름대 하나면 끝 | 0.552 | ○ |
| 일목균형표 구름대 | 0.579 | ○ 띠 상단 (S012 `20일 이평선` 0.592 와 같은 자리) |
| 구름대 매매법 | 0.617 | **✗ 띠 밖** |
| 구름대 추세 읽기 | 0.646 | **✗ 띠 밖** |

**너무 가까우면 배너가 아니라 요약이 된다.** 넘어간 둘은 공통점이 있다 —
주제어(구름대)에 **대본에 자주 나오는 낱말(매매·추세)을 하나 더 붙였다.**
→ **아랫줄 = 주제어 하나 + 대본에 없는 말.** 주제어를 두 개 겹치면 넘친다.

윗줄은 띠가 넓으니 이 잣대로 거를 게 못 된다. 윗줄은 자유롭게 써도 된다는 뜻이다.

## S016 에 적용

**가장 비슷한 과거 회차** (대본 전체끼리)

```
0.680  S012  세 가지만 기억하세요! / 20일 이평선     ← 쌍둥이
0.639  S006  세 가지만 기억하세요! / 이평선 개념정리
0.597  S011  세 가지만 기억하세요! / RSI? 쉽다 쉬워
0.576  S007  아직도 그냥 쓰세요?! / 볼린저밴드의 변신
0.560  S008  추세추종? 역추세?   / 손실 최소화 매매법
0.531  S009  나만의 원칙 만들기  / W.H.W 매매기준
```

카피맵에서 "S012 가 S016 의 쌍둥이"라고 쓴 것이 수치로도 1위다.
다만 **S016 대본에는 "세 가지"가 없어** S012 의 윗줄은 못 쓴다.
S012 의 아랫줄 문법(주제어만 놓기)은 쓸 수 있다.

### 3안 (채점 완료)

**1안 — 통념 도발** (S007 계열)
```
윗줄   선이 많아서 껐다면?      11자   0.462  ○
아랫줄  구름대만 남기세요        9자   0.558  ○ 평균에 가장 가깝다
```
대본 훅을 그대로 줄였다. 아랫줄 점수가 과거 평균(0.550)에 가장 근접한다.

**2안 — 단순화 약속** (S014 계열)
```
윗줄   선 다 볼 필요 없어요     12자   0.507  ○
아랫줄  구름대 하나면 끝         9자   0.552  ○
```
윗줄 점수도 과거 평균(0.500)에 가장 가깝다. 두 줄 다 한가운데에 있는 안이다.

**3안 — 세 구간 대비** (S008·S012 계열) ※ 앞 문서에서 아랫줄을 바꿨다
```
윗줄   위냐 아래냐 안이냐?      11자   0.460  ○
아랫줄  일목균형표 구름대        9자   0.579  ○ 띠 상단
```
앞 문서의 아랫줄 `구름대 추세 읽기`는 **0.646 으로 띠 밖**이라 뺐다.
S012 가 `20일 이평선`으로 주제어만 놓은 것과 같은 자리(0.592)에 서는 문구로 바꿨다.

## 한계

- **대본이 붙는 회차가 6편뿐이다.** 아랫줄 띠(0.496~0.592)는 점 6개로 그은 선이다.
  S013·S014·S010 자막이 생기면 다시 재야 한다.
- 유사도는 "얼마나 비슷한가"만 잰다. **어떤 유형의 윗줄을 쓸지(도발/대비/개수/약속)는
  유사도가 못 정한다** — 그건 앞 문서의 유형 분류가 맡는다. 두 문서를 같이 본다.
- 화면라벨 29개는 타임코드가 없어 '그 회차 어딘가'로만 묶여 있다. prproj 의 클립
  시각까지 읽으면 (내레이션 구간 → 라벨) 쌍이 정확해진다. 다음 과제.

## 다시 돌리기

```bash
python tools/theone/pairs.py <숏폼_프로젝트모음> --out pairs.jsonl
python tools/theone/banner_model.py pairs.jsonl --report
python tools/theone/banner_model.py pairs.jsonl --near  <새대본.srt>
python tools/theone/banner_model.py pairs.jsonl --score <새대본.srt> "후보1" "후보2" …
python tools/theone/banner_model.py pairs.jsonl --chroma <저장폴더>
```

필요한 것: `pip install torch --index-url https://download.pytorch.org/whl/cpu`,
`pip install sentence-transformers chromadb`. 모델은 처음 한 번 2.2GB 내려받는다.

다음 세션에서 이 corpus 를 그대로 꺼내 쓰려면 데스크탑 앱 MCP 설정에 한 줄 —
```json
{"chroma": {"command": "uvx", "args": ["chroma-mcp", "--client-type", "persistent",
 "--data-dir", "…/숏폼_프로젝트모음/_chroma"]}}
```
