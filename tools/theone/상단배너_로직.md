# 더원트레이더 숏폼 — 상단 배너 문구 로직

> 최종본 영상 12편의 배너를 실측하고, 자막(.srt)이 있는 7편은 대본과 대조했다.
> 원본: `01_영상_최종 아웃풋/03_더원 트레이더(최종본)/숏츠_영상(더원)`
> ⚠ 차트명가 아님. 이 시리즈 안에서만 뽑았다.

## 1. 실측 — 배너 12편

인터뷰·광고 편(S001·S004·S005)은 배너 틀이 아예 달라(어두운 상자 + 흰 글씨) 뺐다.

| 회차 | 윗줄 (하늘색 형광) | 아랫줄 (검정 굵게 + 하늘색 하이라이트) | 자막 |
|---|---|---|---|
| S002 | 닿아서 매수했는데?? | 20일 이평선의 배신 | 없음 |
| S003 | 볼린저밴드 이탈은 손실!? | 잡았다! 밴드타기! | 없음 |
| S006 | 세 가지만 기억하세요! | 이평선 개념정리 | ✓ |
| S007 | 아직도 그냥 쓰세요?! | 볼린저밴드의 변신 | ✓ |
| S008 | 추세추종? 역추세? | 손실 최소화 매매법 | ✓ |
| S009 | 나만의 원칙 만들기 | W.H.W 매매기준 | ✓ |
| S010 | 일목균형표 쓰고 있다면 | 다 지우고 '이것'만 | 없음 |
| S011 | 세 가지만 기억하세요! | RSI? 쉽다 쉬워 | ✓ |
| S012 | 세 가지만 기억하세요! | 20일 이평선 | ✓ |
| S013 | 무료로 받아가세요 | 프랙탈 매매지표 | 없음 |
| S014 | 이것만 바꿔보세요! | RSI 스캘핑 매매 | 없음 |
| S015 | 싹 고쳐드립니다 | 포지션 중독? 주목! | ✓ |

## 2. 규격 (띄어쓰기 포함 글자 수)

| | 범위 | 중앙값 |
|---|---|---|
| 윗줄 | 8~14자 | **12자** |
| 아랫줄 | 7~11자 | **10자** |

- **아랫줄이 윗줄보다 길지 않다** — 12편 중 11편. (예외는 S015 뿐: 8/11)
  아랫줄 글자가 훨씬 크니 물리적으로 그렇게 된다. 아랫줄 11자가 사실상 상한이다.
- 윗줄 끝에 `?` 나 `!` — 12편 중 8편. 아랫줄은 2편뿐(S003·S015).
- 두 줄에 같은 낱말을 겹쳐 쓰지 않는다.

## 3. 두 줄의 역할 — 이게 핵심

### 아랫줄 = **무엇에 관한 영상인가** (주제어)

**아랫줄에는 그 편 대본에서 가장 많이 나오는 낱말이 들어간다.** 자막 있는 7편 전부 그렇다.

| 회차 | 대본 최다 출현어 | 아랫줄 |
|---|---|---|
| S006 | 이동평균선(9) | **이평선** 개념정리 (약어) |
| S007 | 밴드(10) | **볼린저밴드**의 변신 |
| S008 | 매매(12) | 손실 최소화 **매매**법 |
| S009 | 지표(4)·기준(3) | W.H.W 매매**기준** |
| S011 | RSI(9) | **RSI**? 쉽다 쉬워 |
| S012 | 이평선(9)·20일(8) | **20일 이평선** |
| S015 | 매매(5)·포지션(3) | **포지션** 중독? 주목! |

즉 아랫줄은 **주제어 + 한 마디**다. 한 마디는 넷 중 하나 —
개념정리 / 변신·배신(반전) / 매매법·기준(방법) / 주목!·쉽다(권유).

### 윗줄 = **왜 봐야 하는가** (대본에서 뽑아 압축)

윗줄은 대본에 실제로 있는 말을 10~12자로 줄인 것이다. 다섯 유형이 쓰인다.

| 유형 | 예 | 대본의 근거 |
|---|---|---|
| **개수 약속** | 세 가지만 기억하세요! (S006·S011·S012) | 대본이 "세 가지"를 셀 때만 쓴다 |
| **통념 도발** | 아직도 그냥 쓰세요?! (S007)<br>닿아서 매수했는데?? (S002)<br>볼린저밴드 이탈은 손실!? (S003) | 훅 문장 그대로 — S007 훅이 "아직도 이렇게 알고 계신다면 완전히 틀렸습니다" |
| **대비 제시** | 추세추종? 역추세? (S008) | 대본이 A와 B를 가를 때. 낱말이 대본과 100% 같다 |
| **조건 걸기** | 일목균형표 쓰고 있다면 (S010) | "…쓰고 있다면" |
| **행동 유도** | 이것만 바꿔보세요! (S014)<br>싹 고쳐드립니다 (S015)<br>무료로 받아가세요 (S013) | 대본 밖에서 새로 쓴다. 지표를 바꾸거나 주는 편에 쓴다 |

**개수 약속형에는 조건이 하나 더 있다** — S009 도 대본에 "이 세 가지를 종합해서"가
있지만 배너는 `나만의 원칙 만들기`다. 개수(W·H·W)가 이미 아랫줄에 들어가 있어서다.
**개수는 두 줄 중 한 곳에만 쓴다.**

## 4. S016 에 적용 — 「복잡한 일목균형표, 구름대만 남기세요」

대본 최다 출현어: **구름대(10)** · 가격(3) · 일목균형표(2) · 추세(2) · 지지(2)
→ **아랫줄에는 반드시 '구름대'가 들어간다.** 일목균형표는 2회뿐이라 주제어가 아니다.
→ 대본에 "N가지"가 없다. **개수 약속형은 쓸 수 없다.**

⚠ **S010(후행스팬)이 이미 `일목균형표 쓰고 있다면 / 다 지우고 '이것'만`을 썼다.**
   같은 일목균형표 편이고 열흘 차이다. 조건 걸기형과 "'이것'만" 어법은 피한다.
   대신 S010 이 감춘 '이것'을 S016 이 이름으로 밝히는 흐름이 자연스럽다.

## 3안

### 1안 — 통념 도발형 (S007·S002·S003 계열)

```
윗줄   선이 많아서 껐다면?      (11자)
아랫줄  구름대만 남기세요        ( 9자)
```

대본 훅 "일목균형표를 켰다가 선이 너무 많아서 바로 꺼버린 적 있으신가요?" 를 그대로
줄였다. 이 시리즈에서 가장 많이 쓰는 유형이고, 훅과 배너가 같은 말을 하니 도입부가
붙는다. 아랫줄은 제목 그대로라 검색·썸네일과도 어긋나지 않는다.
**S010 의 "'이것'만"에 이름을 붙여 주는 뒷편처럼 읽힌다.**

### 2안 — 단순화 약속형 (S014 행동 유도 계열)

```
윗줄   선 다 볼 필요 없어요     (12자)
아랫줄  구름대 하나면 끝        ( 9자)
```

대본 "처음부터 모든 선을 볼 필요는 없습니다" + "저는 가장 먼저 구름대부터 봅니다"
를 두 줄로 나눠 담았다. 윗줄이 부담을 덜어 주고 아랫줄이 답을 준다.
세 안 중 가장 세게 이득을 말한다 — 지표를 줄여 준다는 약속이라 클릭이 붙는 쪽이다.

### 3안 — 세 구간 대비형 (S008 계열)

```
윗줄   위냐 아래냐 안이냐?      (11자)
아랫줄  구름대 추세 읽기        ( 9자)
```

이 편의 뼈대가 그대로 배너가 된다 — "구름대 위에 있다면 상승 추세 / 아래에 있다면
하락 추세 / 안에 들어가 있다면 기다립니다". S008 이 `추세추종? 역추세?` 로 두 갈래를
세운 것과 같은 문법인데, 여기는 세 갈래라 더 궁금해진다.
다만 세 안 중 이득이 가장 덜 드러난다.

## 고를 때

- **훅과 배너를 붙이려면 1안.** 대본 첫 문장이 배너를 그대로 받는다.
- **클릭을 노리면 2안.** 이득("선 다 볼 필요 없다")이 가장 앞에 온다.
- **내용을 정직하게 미리 보여주려면 3안.**

세 안 모두 규격(윗줄 8~14 · 아랫줄 7~11 · 아랫줄≤윗줄) 안이고,
기존 12편 어느 문구와도 겹치지 않는다.
