# 시퀀스 프리셋

`차트명가_1080p_30fps.sqpreset`

프리미어가 기본으로 주는 `HD 1080p` 프리셋에는 **30.0 이 없다** — 23.976 / 25 / 29.97 / 50 / 59.94 뿐이다.
그런데 회사 롱폼 시퀀스의 timebase 는 **30.0** 이다(실측, `log/PREMIERE-LAB.md` 의 '격자' 항목).
29.97 로 만들어서 나중에 회차 시퀀스에 중첩하면 컨폼이 걸린다.

그래서 `HD 1080p 29.97 fps.sqpreset` 을 복사해 `<VideoFrameRate>` 만 바꿨다.

```
8475667200  →  8467200000      29.97 → 30.0 (틱/프레임)
```

나머지(1920x1080, 48kHz, 필드 없음, BT.709)는 손대지 않았다.
`.sqpreset` 은 그냥 XML 이라 이렇게 만들어도 프리미어가 그대로 읽는다.
