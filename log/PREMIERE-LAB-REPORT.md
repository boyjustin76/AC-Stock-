## 3. 매뉴얼 전제 중 사실이 아닌 것

### 3-1. M4 의 "마지막 벽" 은 없었다 — qe 에 `addTracks` 가 있다

M4-c 보고에서 "차트를 원하는 깊이에 놓을 방법이 없다"고 올렸는데, **틀렸다.**

```javascript
app.enableQE();
qe.project.getActiveSequence().addTracks(1, 2, 0, 0, 0, 0, 0, 0);   // 인자 8개
```

인덱스 2 에 비디오 트랙 하나가 들어가고 기존 V2~V10 이 V3~V11 로 밀린다. **내용물 손실 0.**
성패는 반환값이 아니라 **트랙 수 증가 + 새 트랙이 비었는지**로 판정해야 한다.

### 3-2. 프리셋의 0~16초는 "빈 자리" 가 아니라 고정 오프닝이다

파일만 읽어서는 알 수 없었다. **합성 프레임을 뽑아 보고서야 보였다.**

```
 0.00~ 3.50   훅 스틸 + '댓글 유도' 그래픽
 5.93~12.20   인트로 애니메이션(지그재그 + 매수/매도 태그) → 9.60 부터 타이틀 카드
12.20~14.73   비어 있음
14.73~        본문 시작 (프리셋이 차트를 두는 자리 — V1 의 chartA.png)
```

5.93~12.20 은 프리셋 그래픽이 화면의 주인공이라, 거기에 **라벨 붙은 차트를 깔면
매수/매도 태그가 두 벌로 겹치고 글자가 서로를 파묻는다.** 그래서 그 구간은 라벨 없는
배경으로 깔았다. 회차 조립 규칙으로 매뉴얼에 올라가야 한다.

**방법론 함의: `.prproj` 를 뜯어 읽는 것만으로는 레이아웃 판단을 못 한다.**
`qe...exportFramePNG` 로 프레임을 뽑는 것을 검증 절차에 넣어야 한다(§3-5 옆에).

### 3-3. 드라이브 마운트 이름이 다르다 (드라이브 문자만이 아니다)

```
편집자 PC   D:\01_구글 드라이브(파가드AC)\트레이딩팩토리\...
이 PC       G:\내 드라이브\트레이딩팩토리\...
```

## 4. DB 에 넣어 달라

### `prproj_fact` — 시퀀스 생성 (M6, 새로 잼)

| 호출 | 결과 |
|---|---|
| `app.project.createNewSequence(name, id)` | **'새 시퀀스' 모달을 띄운다. 세션이 멈춘다. 금지** |
| `qe.project.newSequence(name, path)` | **`true` 를 주고 아무것도 안 만든다** |
| `app.project.newSequence(name, 역슬래시 .sqpreset 경로)` | **이게 답.** 슬래시면 실패 |
| `app.project.newSequence(name)` | `Not Enough Parameters` |

### `prproj_fact` — 그 외

- `qe...addTracks(n, idx, 0,0,0, 0,0,0)` — 원하는 깊이에 트랙 삽입 (§3-1)
- `qe...exportFramePNG(타임코드, 경로)` — **역슬래시 경로만 받고 확장자를 스스로 붙인다.**
  슬래시면 `Unknown error exception`, `t.png` 를 주면 `t.png.png`. JPEG/TIFF/Targa/DPX 도 같은 규칙
- `qe...getVideoTrackAt(i).setName()` — 트랙 이름 변경 가능
- 키프레임 **마지막 키는 클립 끝 틱이 아니라 끝−1프레임**에 찍어야 한다. 끝 틱은 포함되지 않는 경계다
- 모션 속성 이름은 `비율` 이 아니라 **`비율 조정`**. 같은 모션 안에 `폭 비율 조정`·`균일 비율` 도 있다
- `overwriteClip` 은 덮은 자리의 프리셋 클립과 키프레임을 **오류 없이** 지운다. 새 클립은 프리셋 이펙트를 못 물려받는다
- `clip.end` 는 Time 대입이 된다(문서에 없다). 스틸은 기본 길이보다 길게도 늘어난다

### `constraint_note` — 릴링크

- `relinkMedia` 는 **없다**. `projectItem.changeMediaPath(path, true)` 가 답이고
  `canChangeMediaPath(path)` 로 미리 물어볼 수 있다. **반환값 말고 `getMediaPath()` 를 다시 읽어라**
- 릴링크하면 `OfflineReason` 이 사라지고 FrameRate 집계가 바뀐다(자리표시자 대신 진짜 값을 읽는다). 정상이다

### `constraint_note` — 모달이 세션을 죽인다

`createNewSequence` 호출 뒤 **그 뒤의 모든 잡이 TIMEOUT** 이고 로그도 안 남는다(잡이 끝나야 파일을 쓰니까).
프리미어 창을 열거해서 찾았다:

```
vis=True  en=True   [새 시퀀스]              ← 모달
vis=True  en=False  [Adobe Premiere - ...]   ← 본체가 비활성
```

`WM_CLOSE` 로 닫으니 살아났다. **매뉴얼 §5 에 넣어 달라 — 위험한 호출 앞에서는 로그를 먼저 flush 하고,
TIMEOUT 이 반복되면 프리미어 창 목록부터 열거해라.**

### `brand_token`

`0D9488` — 프리셋 색상 범례 원문: *'반대되는 개념의 서브 강조 (예: 매수/매도, 상승/하락 등 상반된 지표 비교)'*.

## 6. 판단이 필요하다 — 4건

1. **텍스트를 '진짜 텍스트 레이어' 로 갈 것인가.**
   지금은 층으로 갈라서 끄고·켜고·옮기고·타이밍 조절은 되지만 **글자를 다시 칠 수는 없다**(렌더된 영상).
   진짜 텍스트는 Essential Graphics(`.mogrt`) + `sequence.importMGT` 인데 **`.mogrt` 는 스크립트로 못 만든다** —
   프리미어/AE 에서 사람이 한 번 내보내 줘야 한다.
   대안: 프리셋 안에 이미 그래픽 텍스트 클립이 여럿 있으니 **그 소스 텍스트를 바꾸는 길**이 남아 있다(미탐색).
   글자 수정이 흔한 작업이면 뚫어야 하고, 아니면 지금 구조로 간다(텍스트 층만 9초에 재렌더).

2. **A(프리셋에 얹기)와 B(처음부터 만들기) 중 어느 쪽을 본류로 삼을 것인가.**
   A 는 프리셋의 고정 오프닝·로고·타이틀바를 그대로 쓰지만 편집 여지가 좁다.
   B 는 구조가 깨끗하지만 프리셋 그래픽이 없어 그대로는 완성본이 아니다.
   실제 워크플로는 **B 를 만들어 A 에 중첩**하는 것이 맞아 보이는데, 확정이 필요하다.

3. **타이틀·소제목이 아직 차명10 것이다** — "볼린저밴드의 한계를 극복한 매매법", "(타이틀:고정)",
   "(소제목:파트마다 교체)", 타이틀 카드의 "양방향 매매법". 1번과 같은 문제다.

4. **차트가 대본과 어긋나지 않는지 봐 달라** (M4-c 에서 올린 것, 아직 미판정).
   "공식대로 하면 손실"이 되도록 시장 파라미터를 골랐다 — 진입 61,361 → 청산 61,013 = **−0.57%**,
   진입 후 고점은 **+0.44%** 뿐. 연출로 과한지 판단이 필요하다.
   재현: `node src/tools/find-cross.mjs scenes/cmg12-cross.scenes.js`
