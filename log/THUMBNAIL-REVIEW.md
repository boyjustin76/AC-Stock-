## 1. 요지 — 실행 속도는 문제가 아니다. 오독 위험이 문제다

썸네일 도구는 회차당 1회 도는 물건이라 런타임 병목이 없다 (지배 비용인 180MB
템플릿 열기/복제도 타이틀 캐시로 이미 상쇄). 그리고 대화록 확인 결과 **실전 경로는
로컬의 포토샵 JSX**(`tools/photoshop/`, 미푸시)다. 이 저장소의 파이썬 도구들은
"포토샵 없는 컨테이너용 대체 경로"가 됐다 — 그래도 남는 이상 아래는 고칠 가치가 있다.

## 2. 발견 (중요한 순)

### ① 1세대 도구가 살아 있고, 지금 돌리면 "그때 그 틀린 썸네일"이 나온다

> **[처리 2026-08-28]** `tools/legacy/` 로 격리, 실행 금지 헤더 부착 (decision 20).
`tools/thumbnail.py` + `tools/psdwrite.py` 는 처음 시도(효과를 손으로 근사해 그리던
시절)의 짝이다. 서로만 참조하는 고립 계통인데 문제는 **지금도 멀쩡히 실행된다**는 것:

- 획·그림자를 코드로 근사해 그린다 → "효과가 회사 것과 다르다" 지적의 근원
- 종이배경을 **옛 11KB 다운샘플본**(`종이 배경.png`)으로, **불투명 100%**, (4,0) 에 얹는다
  — 실측값(원본 3.1MB · 30% · (4,−84))과 셋 다 다르다
- 틀을 템플릿 픽셀 대신 26px 핑크 사각형으로 다시 그리고, 로고도 다른 파일을 쓴다
- 출력은 포토샵이 두 번 거부한 psdwrite 경로다

**제안**: 두 파일 머리에 "레거시 — 실행 금지, 현행은 thumbnail_png.py(컨테이너) /
tools/photoshop(로컬)" 경고를 달거나 `tools/legacy/` 로 옮긴다. (병합 뒤에.)

### ② 타이틀 크기 로직이 낡은 규칙 위에 서 있다 (대화록 반영으로 승격)
로컬이 완성본을 실측해 **규칙 4·5 를 뒤집었다: 폭 맞춤이 아니라 높이 고정**이다.
그런데 컨테이너 도구는 셋 다 폭 역산으로 짜여 있다 — `thumbnail.py fit_size`
(SUB 1120 / MAIN 1185), `psdedit._fit`, `bake_text(target_width=)`,
그리고 `thumbnail_png.py` 가 넘기는 1185/1120. 컨테이너 대체 경로를 쓰는 날엔
타이틀 크기가 규칙과 어긋난다. CLAUDE.md 의 "폭을 맞춘다" 요약 문장도 병합 후
로컬 기록(brand_token 의 타이틀 고정 높이 2종) 기준으로 고쳐야 한다.

### ③ `thumbnail_png.py` 의 타이틀 캐시가 입력을 안 본다
`titles()` 는 `title_{tag}.txt` 가 **존재하기만 하면** 재사용한다. 문구(VERSIONS)나
템플릿을 바꿔도 옛 타이틀이 조용히 나온다.
**제안**: 캐시 파일명에 (문구·크기·색) 해시를 넣거나, meta 에 spec 을 적고 비교.

### ⑤ 차11 이 소스에 박혀 있다
`VERSIONS` 문구·씬 이름·출력 파일명(`차명#11_...`)이 하드코딩. 로컬 JSX 는 이미
`config.json` 의 group·variants 만 바꾸는 구조로 갔다 — 컨테이너 쪽도 같은
config 를 읽게 맞추면 회차마다 코드 수정이 사라지고 두 경로의 스펙이 한 곳이 된다.

### ⑥ 잔가지
- `build_chart()`: probe 에 없는 태그를 **조용히** 건너뛴다 → 경고 한 줄 필요
- `titles()` 안 `find()`: 레이어 미발견 시 None → AttributeError. 명시적 에러로
- 폭 맞춤 로직이 두 벌 (`fit_size` 40~400 vs `_fit` 20~500) — ①·② 정리 시 자연 해소
- `psdedit._render()` 가 돌려주는 `left_pad` 는 아무도 안 쓴다

## 3. 잘 만들어져 있어 유지할 것

- **probe 컷 좌표 실측** — 차트에 없는 색(자홍·청록)을 찍어 읽는다. 짐작 제거의 정석
- **버튼·틀·로고·종이 = 템플릿 원본 픽셀** (`topil()` 추출). 로컬이 독립 실측한
  값(버튼 189×90 · 화살촉 141~185)과 정확히 일치 — 서로 교차 검증됐다
- `psdedit.check()` — RunArray 짝·lyid 중복·그룹 여닫이를 저장 전에 잡는다
- `bake_text()` 가 획·그림자를 안 그리는 것 — lfx2 가 살아 있어 두 겹 방지
- 종이 30% 산술 검증 (250.2 = 0.3×239.3 + 0.7×255) — 값이 실측에 묶여 있다
