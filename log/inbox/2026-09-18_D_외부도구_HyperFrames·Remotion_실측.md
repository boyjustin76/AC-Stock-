# D → 총괄 (B·E 참조) · HyperFrames · Remotion 을 이 PC 에서 돌려 본 결과 · 2026-09-18

이정찬 지시로 둘을 공식 저장소에서 받아 **직접 돌려 본 것만** 적는다. 받은 곳은 `06_실험실/외부참고/`(hyperframes 1.4G · remotion 1.2G, `--depth 1`). 시험 프로젝트는 `06_실험실/hf_smoke/`.

## 0. 한 줄

**HyperFrames 는 우리 AE 자리를 대신할 수 있다. Remotion 은 라이선스에서 걸린다.** 차트 렌더러는 그대로 두는 게 맞다.

## 1. Remotion — 회사 규모에서 막힌다 (판단: 도입 보류)

`remotion-dev/remotion`. 무료 조건이 **개인 · 직원 3명 이하 영리법인 · 비영리 · 평가 중**이다. 그 위는 **company license(유료)** 다. 우리는 회사 일이고 직원이 3명을 넘으면 유료다. 이정찬의 '유료는 안 한다' 원칙에 걸린다.
기술적으로는 React 로 영상을 짜고 배치 렌더까지 되는, 이 분야의 표준에 가까운 도구다. **회사 인원이 3명 이하가 맞다면** 다시 보면 된다. 그 전까지는 받은 것만 참고용으로 둔다.

## 2. HyperFrames — Apache 2.0, 전부 로컬, 우리 규격이 그대로 나온다

`heygen-com/hyperframes` v0.8.46 · 별 51k · Apache 2.0(상업 사용 자유) · Node ≥22(우리 24.19).
HTML + CSS + GSAP 로 짜고 **결정론적** MP4/MOV/WebM/GIF/PNG시퀀스로 뽑는다. 프레임마다 `time = floor(frame)/fps` 로 계산하고 GSAP 타임라인을 **정지시킨 채 seek** 한다 — 우리 렌더러와 같은 원리다. 로컬 렌더에 HeyGen 크레딧은 안 쓴다(문서 명시).

### 이 PC 에서 확인한 것

`hyperframes doctor` 로 부족한 것을 찾아 **시스템은 안 건드리고** 시험 폴더에만 채웠다 — `ffmpeg-static`·`ffprobe-static`(npm), Chrome 은 `hyperframes browser ensure` 가 `~/.cache` 에 받는다. (참고: 이 PC PATH 에는 ffmpeg 가 없다. 파이썬 쪽은 `imageio_ffmpeg` 안의 ffmpeg 7.1 이 있으나 ffprobe 가 없다.)

| 잰 것 | 결과 |
|---|---|
| 1920×1080 · 10초 · 30fps MP4 | **11.9초** (6코어 i5-9400, 단순 합성) |
| **59.94 유리수 fps** `-f 60000/1001` | 됐다 — ffprobe `r_frame_rate=60000/1001`, 1.001초에 60프레임 |
| **알파 있는 ProRes 4444** `--format mov` | 됐다 — `codec_name=prores`, `pix_fmt=yuva444p10le`, 빈 자리 `(0,0,0,0)` |
| **RGBA PNG 시퀀스** `--format png-sequence` | 됐다 — 60장, 빈 자리 `(0,0,0,0)`. 문서에 "AE/Nuke/Fusion 반입용"이라고 적혀 있다 |
| **브랜드 색 정확도** | 아래 따로 |
| 같은 그림 프레임 건너뛰기 | 자동 — `static-frame dedup: reused 27/30 (90%)`, 2.3초 아꼈다고 로그에 찍힌다 |

### 색 — 여기는 조심해야 한다 (실측)

같은 합성을 두 형식으로 뽑아 픽셀을 쟀다.

| 낸 색 | ProRes 4444(.mov) | PNG 시퀀스 |
|---|---|---|
| `#EF2767` (239,39,103) | (239,39,103) ○ | (239,39,103) ○ |
| `#0D9488` (13,148,136) | **(12,148,135) ✗ 1씩 어긋남** | (13,148,136) ○ |

ProRes 는 YUV 10bit 라 왕복에서 ±1 이 난다. 눈으로는 안 보이지만 **`brand/` 는 실측값이 기준**인 우리 원칙에는 걸린다.
→ **색을 보증해야 하는 것은 PNG 시퀀스로 뽑는다.** 프리미어에 바로 얹는 오버레이는 .mov 가 편하다.

## 3. 그래서 어디에 쓰나 — 우리 파이프라인 기준

**바꾸지 말 것: 차트 컷씬 렌더러(`src/`).** 이미 결정론적이고 브랜드 값이 정확하고 빠르다(benchmark 1·2: 956프레임 15.95초 영상을 순차 93초 → 병렬 45초, 그 뒤 toDataURL 로 컷 하나 26.8초). 바꿀 이유가 없다.

**바꿀 만한 것: AE 가 하던 겹치기(오버레이) 자리.** 지금 AE 는 COM 으로 띄우고, 대화상자·mogrt 누락·"프리미어가 켜져 있으면 잡이 프리미어의 AE 로 간다" 같은 함정이 줄줄이 있다(constraint_note·TRAPS). HyperFrames 로 하면:
- 브라우저만 쓰므로 **어도비 앱을 안 띄운다** — 남이 쓰는 중인 앱과 부딪힐 일이 없다.
- **59.94 유리수 fps 가 그대로** 나온다. 우리 롱폼 규격이다.
- **알파가 나온다** — 프리미어에 얹는 로어서드·태그·밴드·스팅이 여기 해당한다.
- `--variables` / `--batch` 로 **회차별로 값만 바꿔 한 번에** 뽑는다. 숏폼 25편처럼 같은 틀에 값만 다른 것에 맞는다.
- `lint` · `check` · `snapshot` · `compare` · `keyframes`(어니언 스킨) 같은 검사 명령이 붙어 있다. 우리가 `--stills` 와 `probe-labels.mjs` 로 손으로 하던 자리다.

**안 맞는 것**: 차트 캔들·밴드처럼 우리 데이터로 그리는 것. 그건 우리 렌더러가 낫다.

## 4. 지금 상태 · 남은 판단

- 스킬 9개(`hyperframes` 라우터 외)가 **사용자 폴더 `~/.claude/skills/`** 에 깔렸다 — 이 PC 의 모든 세션(B·E 포함)이 쓴다. **저장소 `.claude/` 는 안 건드렸다**(`git status` 로 확인).
- 켜 둔 것: `HYPERFRAMES_NO_TELEMETRY=1`. 이 도구는 기본적으로 익명 렌더 통계를 보낸다. 공개 저장소라도 회사 작업 이름이 나가는 건 막는 게 맞다고 봤다.
- **총괄 판단이 필요한 것**
  1. AE 잡 중 무엇을 먼저 옮길지. 내 제안은 **알파 오버레이 한 건**으로 시작해 AE 결과물과 픽셀 비교를 붙이는 것이다.
  2. 옮긴다면 `tools/hf/` 를 저장소에 만들지. 지금 시험은 `06_실험실/hf_smoke/`(저장소 밖)에 있다.
  3. `06_실험실/외부참고/` 2.6GB 를 남길지 지울지. 남기면 참고가 되고, 지워도 다시 받으면 된다.
- 이정찬 확인이 필요한 것: **회사 직원이 3명 이하인가** — 그렇다면 Remotion 도 무료다.
