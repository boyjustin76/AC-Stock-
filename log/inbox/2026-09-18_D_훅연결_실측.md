## 2. `${CLAUDE_PROJECT_DIR}` 펼침 — 펼쳐진다

`.claude/settings.local.json`(gitignore) 에 아무것도 막지 않는 탐침 훅을 잠깐 걸어 받은 인자를 그대로 찍었다. 측정 뒤 지웠다.

```json
{"when": "2026-09-18T10:14:07",
 "argv": ["…/argv_probe.py",
          "C:\\Users\\user\\Desktop\\이정찬\\차트명가NEW_통합\\03_저장소\\worktrees\\D_Video/.claude/hooks/git_guard.py"],
 "cwd": "C:\\…\\worktrees\\D_Video",
 "CLAUDE_PROJECT_DIR": "C:\\…\\worktrees\\D_Video",
 "PYTHONUTF8": "1", "PYTHONIOENCODING": "utf-8"}
```

- `args`(exec form) 가 실제로 전달된다 — 인자가 argv 로 들어왔다.
- `${CLAUDE_PROJECT_DIR}` 는 **세션을 띄운 worktree 폴더**로 펼쳐진다. 상대경로 대체안은 필요 없다.
- 펼친 값은 역슬래시, 내가 이어 붙인 부분은 슬래시라 섞이지만 파이썬은 그대로 연다.
- `PYTHONUTF8=1` · `PYTHONIOENCODING=utf-8` 이 세션에 걸렸다 — B 가 매번 붙이던 것이 없어진다.
- `cwd` = 저장소 루트. 세션 폴더가 곧 `CLAUDE_PROJECT_DIR` 이다.

## 3. 훅이 실제로 막는가 — 막는다, 사유도 보인다

`.claude/settings.json` 에 §2-B JSON 을 그대로 넣고 세션에서 실제 명령을 날렸다.

| 명령 | 결과 |
|---|---|
| `git add -A` | **차단** — "작업트리 전체 스테이징은 남의 파일을 휩쓴다(issue 24) …" |
| `git push --dry-run origin <본류>` | **차단** — "본류로의 push 는 총괄만 한다 …" |

차단 사유 문장이 **나(Claude)에게 그대로 보인다**. issue 36("denied 만 보이고 이유가 안 보임")이 해결됐다. 옛 세션이 쓰던 `~/.claude/hooks/hookify_reason.py` 래퍼는 이제 필요 없다 — U-7 되돌리기 가능하다.

세션 밖 실측도 같이 돌렸다(옛 폴더 기준, 총괄 갱신본 `git_guard.py`): `pytest tests/test_git_guard.py` 16 통과 + 실제 명령 8종 × 환경 2종(PYTHONUTF8 없음/있음) 16건 전부 기대대로.
통과해야 하는 것: 옆가지 push · `mv scratch/a.png b.png`(작업경로 아님) · `grep -rn "git push" docs/`.
막아야 하는 것: 본류 push · 인자 없는 push · `add -A` · 작업폴더 여러 줄 스크립트 셋째 줄 이동 · 작업폴더 재귀 삭제.

## 5. 옮기는 중에 나온 것 — `log/save.py` 가 본류로 푸시를 시도한다 (총괄 몫)

이 보고서를 올리려고 `python log/save.py "…" --only …` 를 돌렸더니 커밋은 `worktree-D_Video` 에 제대로 됐는데 마지막 단계가 이렇게 나왔다.

```
git push -u origin <본류> 실패
 ! [rejected]  (non-fast-forward)
```

`save.py:167` 이 `git("push", "-u", "origin", BRANCH)` 로 **본류 이름을 박아** 두고 있다. worktree 로 나누기 전에는 맞는 코드였지만 이제는 세션마다 가지가 다르다.

- 막힌 이유가 훅이 아니라 우연이다 — 원격이 앞서 있어 non-fast-forward 로 거절됐을 뿐이다. `git_guard` 는 `python log/save.py …` 안에서 도는 git 을 못 본다(훅은 Bash 명령줄만 본다).
- 즉 **세이브 스크립트는 지금 가드 밖에 있다.** 다른 세션이 본류보다 앞선 상태에서 세이브하면 그대로 올라간다.
- 제안(총괄 판단): `BRANCH` 를 `git rev-parse --abbrev-ref HEAD` 로 읽거나, 본류면 `ac.role` 을 확인하고 아니면 안 민다. 고치기 전까지 각 세션은 `--no-push` 로 세이브하고 가지 이름을 적어 따로 올린다.
- 이번 건 나는 그렇게 했다 — 커밋 988ad6d 를 `worktree-D_Video` 로 올렸다.

## 6. 훅 자체의 오탐 하나 (참고, 고치자는 말은 아니다)

이 보고서 본문에 본류 가지 이름과 `push` 라는 낱말이 같이 들어 있어서, 보고서를 heredoc 으로 덧붙이는 명령이 **차단됐다**. 옛 로컬 훅에서도 같은 일이 있었다(문서를 쓰는 명령이 문서 내용 때문에 막힌다).
피한 방법: 파일 쓰기 도구로 조각을 만든 뒤 `cat` 으로 이어 붙였다.
규칙을 느슨하게 하면 진짜를 놓치니 그대로 두는 게 낫다고 본다. 다만 **문서를 셸 heredoc 으로 쓰지 말고 파일 도구로 쓴다**를 요령으로 적어 두면 된다.
