## 1. 결과를 믿지 말고 다시 읽는다 (사고가 가장 많이 난 자리)

**B 에게**: 디자인 카피도 같은 함정이 있다. 포토샵 잡이 "레이어를 바꿨다" 고 말해도, **바꾼 뒤 그 레이어를 다시 읽어** 값이 맞는지 봐야 한다.
색·좌표·글자 크기는 결과 PSD/PNG 에서 **다시 재서** 확인하는 게 가장 싸다.

## 2. 래칫 시험 — 자가발전의 뼈대

새 기능을 넣을 때마다 시험이 같이 자란다. 지금 96개가 외부 앱 없이 돈다.

1. **기능 하나 = 전용 함수 하나.** 남의 계산을 빌려 쓰면 시험이 깨진다(등록 안 된 이름은 오류).
   — 지지선 이탈이 '고점 뒤 하락' 계산을 빌려 써서 아무 구간이나 뽑힌 사고에서 나왔다.
2. **가짜 입력에 진짜 하나 + 헷갈리는 미끼 하나를 심고**, 진짜를 고르는지 본다. 미끼는 *실제로 틀렸던 모양*으로 만든다.
3. **불변식**: 점수는 비율(값을 1000배 해도 같아야 함)·0~1, 1등 점수가 여러 곳에 몰리면 경고.
4. **되살리기(뮤테이션)**: 고친 잘못을 일부러 다시 넣어 시험이 잡는지 확인한다. 오늘까지 4건 모두 잡혔다.

**B 에게**: 규격(타이틀 높이 141/194px, 외곽선 6px, 자간 −40 같은 실측값)은 이 구조와 잘 맞는다.
규격마다 검사 함수 하나 + "틀렸던 모양"(예: 폭에서 역산한 크기)을 미끼로 넣으면, 김직선 규격으로 갈아탈 때도 옛 실수가 다시 안 든다.

## 3. Jev 를 어디에 쓰나 (이정찬: 많이 맡겨라)

- **쓴다**: 뜻만으로 갈리는 판단. 예 — "이 대본 대목엔 어떤 차트 움직임?", "이 대목의 가격 방향은?", 모달 문구 분류, 오류 분류(11/12).
- **안 쓴다**: 수를 견주는 자리(0→0 인지, 목록이 같은지) — confidence 0.9 로 자신 있게 틀린다(D-4). **그림도 못 본다**(글자만).
- **정확도를 올린 것**: 선택지 설명을 차트 말이 아니라 **'대본이 이런 말을 할 때 → 화면은 이렇게'** 로 바꿨더니 0.46 → **0.97**.
  B 도 같은 꼴로 쓰면 좋다 — '원본이 이런 느낌일 때 → 이 요소는 이렇게'.
- **문**: 규칙이 못 잡은 자리 0.7, **규칙을 뒤집으려면 0.8**. 낱말 규칙은 뜻을 거꾸로 읽는다(예: "20일선이 지지선 역할" 을 지지선 *붕괴* 로).

## 4. 서브에이전트 — 그림 판독·검수

- 그림 수십 장 판독(팀장 그림 60장 → 종목·주기·지표·움직임 표)과 결과물 검수(내가 찍은 35장 → 패턴/대본 적합 판정)를
  서브에이전트에게 맡겼다. **시야가 있어 그림을 본다.** 결과는 JSON 으로 받아 내 표와 대조한다.
- 값도 시간도 싸다(한 번에 2~5분). 검수에서 실제로 촬영 버그 하나와 낱말 규칙 오독 둘을 찾았다.

**B 에게**: 김직선 채널 화면 캡처를 수십 장 뜯을 때 이 방식이 제일 빠르다. "요소 목록 + 좌표 + 색"을 JSON 으로 받게 시키고, **픽셀 실측으로 검증**해라.

## 5. 속도

- **같은 탐색은 한 번만** (결과 캐시): 한 장 30초 → 11초. 차11 35장 390초.
- **한 장마다 저장 + `--resume`**: 끊겨도 이어 찍는다.
- 오래 걸리는 것은 백그라운드로 돌리고 Monitor 로 끝날 때 알림을 받는다.

## 6. 외부 앱(어도비·MT5) 다루기 — 사고로 배운 것

- **강제 종료하면 다음 실행이 막힌다**: AE 는 다시 띄울 때 '충돌 복구 옵션' 창이 뜬다 → 시작 전·대기 중 검사해서 **0.2초/15.5초에 멈추고** 사람에게 말한다(전엔 70초 태우고 실패). 일러스트레이터는 재현 안 됨(B 확인).
- **좌표 클릭은 하지 않는다**: 내 클릭이 빗나가 **프리미어가 떠 버렸다**. 총괄 판단도 "막고 말하기 > 대신 해 주기".
- **창 크기를 고정한다**: 창이 바뀌면 화면에 담기는 양이 달라져 결과가 재현되지 않는다.
- **판정 줄**: 잡이 스스로 `판정: …` 한 줄을 쓴다. 밖에서 읽어 맞히려 하지 않는다(Jev 로도 안 된다 — 규칙보다 낮았다).
