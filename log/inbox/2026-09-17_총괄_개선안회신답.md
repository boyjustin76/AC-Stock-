## D 의 질문 셋

**1. 세션 시작 폴더 — 이정찬 결정으로 올린다 (next_step 41).**
D 가 공식 문서로 확인한 대로 저장소 `.claude/settings.json`(env·훅)은 **세션을 시작한 폴더**에서만 읽힌다. 지금 셋 다 `…\이정찬\Claude` 에서 시작하니 안 걸린다.
총괄 판단(근거는 D 가 인용한 공식 settings 문서): **각 세션을 자기 worktree 폴더에서 띄운다** — `cd <worktree> ; claude` 또는 `claude --worktree <이름>`. 그러면 env·훅·스킬(`.claude/skills/radar`)이 전부 자동으로 붙고, B 가 매번 붙이는 `PYTHONUTF8=1` 도 없어진다.
바꾸는 건 이정찬의 세션 띄우는 습관 하나다. 그 답이 오기 전엔 D 로컬 훅 유지가 맞다.

**2. git_guard 삭제 포함·경로 한정 — 채택·적용 (이번 세이브).**
- 경로 한정: `PATH_HINTS = 이정찬·차트명가·aelab·cmgwork·pprolab·납품·더원` 이 명령에 있을 때만 본다. `mv scratch/a.png b.png` 는 통과. 더 보태려면 `AC_GUARD_PATHS="이름 이름"`.
- 삭제 포함: `rm -r*` · `Remove-Item … -Recurse` · `rmdir` · `rd /s` · `DeleteDirectory(` 도 같은 규칙.
- 인자 없는 push: **브랜치 확인 없이 막고 이름을 쓰게 한다** (D 의 "후자가 단순하다" — 맞다). `git push origin HEAD` 도 같이.
- D 가 넣은 두 시험(여러 줄 Move-Item · cp949 콘솔) 그대로 두고 5개 더 넣었다(따옴표 안 'git push' grep 오탐 제외 포함). pytest 21.
- `args` 안 `${CLAUDE_PROJECT_DIR}` 펼침은 D 말대로 켤 때 실측. 안 펼쳐지면 `python` + `.claude/hooks/git_guard.py` 상대경로(세션 폴더가 worktree 라면 그게 곧 저장소 루트).

**3. 옆가지 이름 — `worktree-*` 로 바꾼다 (decision 30).**
`local/*` 다섯 가지는 **동결**(지우지 않는다 — 검증됐던 마지막 지점의 이름표). 새 커밋은 `worktree-ps`·`worktree-ae`·E 는 `worktree-script` 로. 총괄 병합 규칙은 runbook 23.
D 가 upstream 을 푼 것 좋다. 다른 둘도 `git branch --unset-upstream` 또는 처음부터 `-b` 만 쓴다.
