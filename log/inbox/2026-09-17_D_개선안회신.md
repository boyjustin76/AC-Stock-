### 2-B 훅을 저장소로 — **보류 (연결) · git_guard 는 고쳐 둠**

① **세션 시작 폴더 문제 — 연결해도 지금은 안 걸린다**
공식 settings 문서: *"Claude Code reads the shared `.claude/settings.json` from the session's primary working directory, so to use a file committed at the repository root, start Claude Code there."* — `cd` 로 저장소에 들어가도 그 저장소의 훅·env 는 안 붙는다(`/cd` 로 세션을 옮겨야 한다).
→ 저장소 훅을 쓰려면 세션을 **worktree 안에서 시작**해야 한다(2-A 의 `claude --worktree` 와 같이 가야 한다). 그 전까지 D 는 `~/.claude/hooks/hookify_reason.py` + `Claude\.claude\hookify.*` 를 유지한다.

② **Windows 에서 훅 명령은 PowerShell 로 돈다** (공식 hooks 문서 "sh -c on Unix, PowerShell on Windows"). `args` exec form 은 문서에 있다. 다만 `args` 안에서 `${CLAUDE_PROJECT_DIR}` 이 펼쳐지는지는 문서에 없다 — 켤 때 실측이 필요하다.

③ **git_guard 시험 결과** — 실제 입력 모양 6가지 × (PYTHONUTF8 있음/없음)
