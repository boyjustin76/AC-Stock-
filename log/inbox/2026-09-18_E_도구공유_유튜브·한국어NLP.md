## 1. 키 — 이정찬이 발급, 저장소 밖에 둔다

```
C:\Users\user\.secrets\ac_keys.env      ← YOUTUBE_API_KEY · HF_TOKEN
```
**저장소(AC-Stock-)는 public 이라 키를 커밋하면 안 된다.** 꾸러미 zip 도 G드라이브로 올라가니 그 안에도 두지 않는다.
읽는 법:
```python
env = dict(l.strip().split("=", 1) for l in open(r"C:\Users\user\.secrets\ac_keys.env", encoding="utf-8")
           if "=" in l and not l.startswith("#"))
```

## 2. yt-dlp — 유튜브에서 받는 것 전부 (키 불필요)

`pip install -U yt-dlp` (지금 2026.08.19). 유튜브가 추출 경로를 자주 바꾸니 **월 1회 갱신**.

| 하려는 것 | 명령 (검증함) |
|---|---|
| 한국어 자막 | `python -m yt_dlp --js-runtimes node --skip-download --write-auto-subs --sub-langs "ko-orig" --sub-format "srt/vtt" -o "%(id)s.%(ext)s" <URL>` |
| **썸네일 원본** | `--skip-download --write-thumbnail` → **1280×720 webp** (B 에게 쓸모 있을 것) |
| 영상 지표 | `--skip-download --print "%(view_count)s|%(like_count)s|%(upload_date)s|%(title)s" <URL>` |
| 채널 목록 | `--flat-playlist --print "%(id)s|%(view_count)s|%(title)s" "https://www.youtube.com/@핸들/videos"` |
| 구독자 | `--flat-playlist -I 1:1 --print "playlist:%(channel_follower_count)s" <채널URL>` |
| 검색 | `--flat-playlist --print "%(channel)s|%(view_count)s|%(title)s" "ytsearch30:키워드"` |
| 댓글 | `--write-comments --extractor-args "youtube:comment_sort=top;max_comments=20,all,all,20"` |

**함정 넷 (전부 직접 밟았다)**
1. **`--print` 는 `--simulate` 를 함축한다** → 자막·썸네일이 안 받아진다. 같이 쓰려면 `--no-simulate`.
2. **`--convert-subs` 는 ffmpeg 를 부른다**(이 PC 에 없다). 대신 **`--sub-format srt`** — 유튜브가 SRT 를 그냥 준다. 같은 영상에서 **json3 130KB → srt 18KB**, 중복 줄도 정리돼 있다.
3. **`--js-runtimes node`** 를 붙인다. 없으면 "JS 런타임 없음" 경고가 뜬다(Node 24 이미 있음).
4. 자막 언어는 **`ko-orig`(원본) 먼저, 없으면 `ko`**. 두 트랙이 다 있는 영상이 있다.

**약관** — yt-dlp 로 남의 영상을 받는 것은 유튜브 약관 위반이다(제재는 계정 차단). 참고용으로 받는 것과 재배포는 다른 문제다. 로그인 쿠키(`--cookies-from-browser`)는 안 쓰는 쪽이 안전하다.

## 3. YouTube Data API — 좋아요 수·정확한 통계가 필요할 때만

키 하나로 `videos.list` · `channels.list` · `commentThreads.list` · `playlistItems.list` 가 된다(각 1유닛, 하루 10,000).
**`search.list` 만 하루 100콜 별도 한도**라 안 쓰는 게 좋다 — 검색은 위 yt-dlp `ytsearchN:` 으로 대신한다.
- **yt-dlp 가 못 가져오는 것: 좋아요 수.** 이것 때문에 API 를 쓴다.
- **남의 채널 자막은 API 로 못 받는다**(자기 채널만). 403 이 정상이다.
- API 로 받은 남의 채널 데이터는 약관상 **30일 넘게 원본 보관 금지**.

## 4. 한국어 도구 (키 불필요)

| 도구 | 설치 | 쓸 곳 | 확인한 것 |
|---|---|---|---|
| **kiwipiepy** | `pip install kiwipiepy` | 형태소·문장 분리·띄어쓰기 교정 | 용어를 `add_user_word("밴드워크","NNG",5)` 로 물려야 한 낱말로 잡는다 |
| **맞춤법 MCP** | `npx -y @winterjung/mcp-korean-spell` | 문구 교정 | 붙어 버린 글자 3건을 정확히 교정 |
| **KURE-v1** | `pip install sentence-transformers` → `SentenceTransformer("nlpai-lab/KURE-v1")` | 한국어 유사도·비슷한 자료 찾기 | 대본 11편에서 주제가 맞는 것을 정확히 1순위로 집었다 |

**함정**
- 맞춤법 MCP 는 **네이버 검사기를 비공식으로 쓰는 것**이다. 같은 방식의 `py-hanspell` 은 이미 죽었다. 자동 파이프라인에 넣지 말고 사람이 볼 때만.
- 그 MCP 는 **우리가 정한 용어도 고친다**(`메인밴드`→`메인 밴드`). 고유 용어는 예외 목록으로 지켜야 한다.
- Kiwi 자동 띄어쓰기(`space()`)도 **과교정**한다(`매매 법`, `21 기간`). **고칠 자리를 찾는 용도**로만.
- **로컬 맞춤법 모델 `j5ng/et5-typos-corrector` 는 반려했다** — 돌려 보니 `하락 구조`를 **`상승 구조`로 바꿔 놓는다**. 뜻이 바뀌는 교정기는 쓰면 안 된다.
- **KURE-v2 가 리더보드 1위지만 우리 자리에선 v1 이 낫다** — 같은 11편 인코딩에 **v1 68초 · v2 250초**(v2 는 멀티벡터라 계산량이 많다).
- 모델 처음 받을 때 `ValueError: tiktoken is required` 가 나면 `pip install tiktoken sentencepiece protobuf`.

## 5. MCP 가 실제로 뜨는지 먼저 보는 법

설정에 등록하기 전에 그 자리에서 띄워 보는 스크립트를 만들어 뒀다 — initialize → tools/list → tools/call 까지 해 본다.
```
scratchpad/mcp_probe.py   (세션 임시폴더. 필요하면 저장소로 올린다)
python mcp_probe.py "npx -y @winterjung/mcp-korean-spell" fix_korean_spell '{"text":"검사할 문장"}'
```
유명한 유튜브 자막 MCP 중 `kimtaeyoon83/mcp-server-youtube-transcript`(별 595개)는 **npm 배포가 2024-11 에서 멈춰 빈 문자열을 돌려준다.** 별 수를 믿지 말고 띄워 보고 판단하는 게 맞다.

## 6. 윈도우 함정 하나 더
**폴더 이름 끝의 공백·마침표는 윈도우가 조용히 떼어 낸다.** 채널 이름으로 폴더를 만들었더니 `os.makedirs` 는 통과하고 `os.listdir` 이 "경로를 찾을 수 없습니다"로 터졌다. 이름을 쓸 때 `name.strip(" .")` 을 넣는다.
