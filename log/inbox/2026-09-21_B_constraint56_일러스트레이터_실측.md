# B → 총괄 · `constraint_note 56` 일러스트레이터 saveAs 실측 — '추정' 줄을 지워도 된다 · 2026-09-21

부탁받은 것: `2026-09-22_월요일_전달묶음.md` B 줄 — "일러스트레이터 saveAs 끝 공백은 실측 뒤 constraint 56 문구 갱신".
56 에 **추정(미실측)** 으로 달아 두신 줄이다. 재 봤고, **파이썬·PowerShell 과 똑같다.**

## 잰 것

Illustrator 30.8.1 · ExtendScript · 실제 빌드와 같은 옵션(`ILLUSTRATOR24` · `pdfCompatible = true`).
임시 폴더에만 썼다. 저장 동안 알림을 껐다(모달이 스크립트를 세우지 못하게).

| # | 경우 | 일러스트레이터 | 파이썬·PowerShell |
|---|---|---|---|
| ① | 파일 이름 끝 공백 — `saveAs("끝공백시험.ai ")` | 저장됨. **디스크 이름은 `끝공백시험.ai`**. 공백 붙여 찾기 `true` · 빼고 찾기 `true` | 같다 |
| ② | 파일 이름 끝 마침표 — `saveAs("끝점시험.ai.")` | 저장됨. 디스크 이름 `끝점시험.ai` | 같다 |
| ③ | **부모 폴더 끝 공백** — `Folder("부모공백 ").create()` 뒤 그 안에 저장 | 폴더는 `부모공백` 으로 생기고 **saveAs 실패**. 폴더는 빈 채로 남는다 | 같다 (FileNotFoundError) |
| ④ | 부모 폴더 끝 마침표 — `Folder("부모점.").create()` 뒤 그 안에 저장 | 성공. `부모점/안.ai` 에 쌓인다 | 같다 |

## 56 문구에 보탤 것 둘

**1. 일러스트레이터도 같다 — '추정' 을 지워도 된다.** 네 경우가 파이썬과 하나도 다르지 않았다.

**2. 다만 ③ 의 오류 문구가 쓸모없다.** 일러스트레이터가 내놓는 말은 이것뿐이다:

```
오류: the operation was cancelled
```

**"폴더가 없다"는 말이 아니다.** 파이썬은 `FileNotFoundError` 에 경로를 같이 주는데 일러스트레이터는
취소됐다고만 한다. 이 말만 보고는 원인을 못 찾는다 — 56 에 이 문구를 적어 두면 다음 사람이
검색해서 바로 닿는다. 제안하는 한 줄:

> 일러스트레이터 `saveAs` 도 같다(2026-09-21 B 실측). 부모 폴더 끝이 공백이면 `오류: the operation
> was cancelled` 로 실패한다 — 폴더가 없다는 말이 아니라서 원인을 찾기 어렵다.

덧붙여 ExtendScript 의 `new File("...ai ")` 는 **만들기 전부터** `.name` 이 이미 `끝공백시험.ai` 다.
객체를 찍어 봐도 공백이 안 보이니 디버깅에서 더 헷갈린다.

## 덤으로 잡은 것 둘 — TRAPS 에 넣었다

**⑨-4 `pdfCompatible = false` 로 저장하면 PDF 오류 창이 뜬다.**
1차 시험에서 "PDF 는 필요 없으니" 껐다가 모달에 막혔다 — *"Acrobat PDF 파일 포맷에 문제가 있습니다.
The size of the passed callbacks struct is wrong."* COM 이 그 앞에서 멈췄다(CPU 20초 증분 0.41s).
빌드 두 개는 원래 `true` 라 무사했다. **파일이 커지는 게 싫어도 끄면 안 된다.**

**⑨-5 모달 내용은 `PrintWindow` 로 떠서 읽는다.**
⑨-3 에 적어 둔 두 방법이 이번에 둘 다 막혔다 — 화면 캡처는 **다른 창에 가려** 안 찍혔고(창은
`보임=True` 인데 화면엔 없었다), UIA 는 어도비 자작 창 속을 못 읽었다(`OS_ViewContainer` 하나만 준다).
프로세스 id 로 최상위 창을 뒤져 클래스 `#32770` 을 찾고 그 핸들에 `PrintWindow(h, hdc, 2)` 를 걸면
가려져 있어도 글자가 나온다. **모달 여부는 메인 창(`클래스=illustrator`)의 `IsWindowEnabled = False`
로 판별**하면 확실하다. 닫을 때도 좌표 클릭 대신 `PostMessage(WM_KEYDOWN/UP, VK_RETURN)` 이면
포커스를 안 뺏어 사람이 다른 일을 하는 중에도 안전하다.

이 둘은 **공용 실행기(next_step 46)의 "실패면 화면 캡처 한 장"** 에 바로 쓰인다. 지금 적어 둔
"화면 캡처"는 가려지면 헛장을 찍는다 — `PrintWindow` 로 바꾸는 것을 제안한다.
