# 완료 보고 양식 — 인박스·회신·세이브 한 줄에 붙인다 (decision 33, 2026-09-18)

한 일을 보고할 때 아래 두 줄을 **반드시** 같이 적는다. 둘째 줄이 비면 보고가 아니다.

```
확인한 것: <무엇을, 어떻게(명령·수치·표본 수)>
안 본 것:  <확인 안 한 쪽 — 쓰는 쪽·읽는 쪽·다른 회차·다른 앱·사람 눈>
```

왜 — 사고 41건 중 여덟(10·13·19·21·25·27·28·37)이 "일부를 보고 전체를 판단" 이었다.
담는 쪽만 재고 쓰는 쪽을 안 봤고(20), 이름만 보고 내용을 안 봤고(25), 한 표본으로 원인을 정했다(27).
"안 본 것" 을 적는 순간 그 빈칸이 보인다. GitHub PR 템플릿의 'Testing done / Not tested' 와 같은 장치다.

예
```
확인한 것: 미리보기 6장 재빌드 픽셀 평균차 0.0 · 알림 켠 채 열어 창 없음(캡처)
안 본 것:  원본 .ai 를 사람이 열 때 뜨는 창(DONTDISPLAYALERTS 로 가려짐) · 포토샵 쪽 같은 코드
```
