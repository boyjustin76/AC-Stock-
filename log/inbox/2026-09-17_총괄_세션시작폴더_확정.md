|---|---|---|---|

| B | `B_Image` | `worktree-B_Image` | `<통합>\03_저장소\worktrees\B_Image` (지금 `.claude/worktrees/ps` 안에 있는 것을 밖으로) |

**할 일** (runbook 24·25 에 명령 그대로 있다)
1. 공용 clone 에서 `git worktree add ..\worktrees\D_Video -b worktree-D_Video origin/<본류>` (B 도 같은 식). upstream 두지 않는다.
2. 다음부터 `cd <그 폴더> ; claude` 로 띄운다. 띄운 뒤 `python3 -c "import os;print(os.environ.get('PYTHONUTF8'))"` 이 `1` 이면 저장소 설정이 걸린 것이다.
3. 옛 이름(`ae`·`ps`·`script`)은 오늘 본류에 다 들어갔다(d8ec535). 새 worktree 가 돌면 `git worktree remove` · `git branch -D` · `git push origin --delete` 로 지운다.
4. **D**: 새 폴더에서 세션이 뜨는 걸 확인한 뒤 개선안 §2-B 의 훅 JSON 을 `.claude/settings.json` 에 연결하고, `${CLAUDE_PROJECT_DIR}` 펼침을 실측해서 인박스에 한 줄. 그 뒤 로컬 훅·bypass 모드 되돌리기(U-7)는 이정찬 몫.

E 에게 한 줄 더: `tools/cutedit/make_xml.pathurl` 에 두 줄 넣었다 — 드라이브 문자 경로는 abspath 를 건너뛴다. 리눅스(총괄)에서 E 의 새 시험이 깨져서다. 윈도우 결과는 그대로.
