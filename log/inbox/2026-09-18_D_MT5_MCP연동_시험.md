# D → 총괄 · MT5 MCP 붙여 봤다 · 차트 화면을 배경으로 쓰는 것까지 · 2026-09-18

이정찬 지시. MT5(HedgeHood, 데모계좌)의 **내부 MCP 서버**가 켜져 있어 붙여 봤다. 아주 짧은 시험이다.

## 1. 붙는다

- 주소 `http://127.0.0.1:22346/mcp` · 인증 `Authorization: Bearer <키>` (401 응답 헤더가 `WWW-Authenticate: Bearer realm="MetaTrader5-MCP"` 라고 알려 준다).
- **키는 여기 안 적는다** — 저장소가 public 이다. MT5 설정 창(도구 > 옵션 > MCP)에 있고, 쓸 거면 `C:\Users\user\.secrets\` 로 옮기는 게 맞다 (E 가 쓰는 방식).
- 걸린 것 둘:
  1. `initialize` 뒤 **`notifications/initialized` 를 id 없이** 보내야 세션이 열린다. id 를 붙이면 서버가 요청으로 보고 `MCP session is not initialized` 를 돌려준다.
  2. 이어지는 모든 호출에 `Mcp-Session-Id` 헤더를 실어야 한다.

## 2. 도구 50개 — **차트 스크린샷 도구는 없다**

쓸 만한 것만:

| 도구 | 쓸 곳 |
|---|---|
| `get_chart_history` | **심볼·주기별 실제 OHLC** (symbol·period·from·to·limit). US100. M2 를 받아 확인했다 |
| `list_open_charts` | 열린 차트의 심볼·주기·보이는 봉 수·지표 목록·창 크기. 지금 것: `US100. M2` · 117봉 · MA10 · MA34 · RSI(14) · 1920×608 |
| `get_chart_ticks_history` | 틱 |
| `chart_open` · `chart_apply_template` · `chart_add_indicator` | 차트를 코드로 열고 템플릿·지표 걸기 |
| `get_marketwatch_symbols` · `get_trading_account_info` · `get_trading_history_*` | 심볼·계좌·체결 이력 |
| 파일 도구 12종 · `send_web_request` · 전략 테스터 8종 · 저널 3종 | — |
| **거래 도구 7종** (`trade_send_market_order` 등) | **우리 작업에 필요 없다. 부르지 않는다.** 실계좌로 바뀌면 진짜 주문이 나간다 |

## 3. 화면을 '그대로' 가져오는 법 — MCP 말고 창 캡처

MCP 에 스크린샷이 없으니 **`PrintWindow(PW_RENDERFULLCONTENT)`** 로 MT5 창을 직접 찍었다. 창이 다른 모니터에 있거나 가려져 있어도 찍힌다(이 PC 는 MT5 가 보조 모니터에 있다). 1920×987 원본이 그대로 나온다.
다른 방법인 MQL5 `ChartScreenShot()` 은 스크립트를 컴파일해서 차트에 올려야 하는데, MCP 도구에 실행 수단이 없어 사람 손이 필요하다. 지금은 창 캡처가 싸다.

## 4. 얹어 본 것 (3초 · 1920×1080 · 59.94fps)

`06_실험실/mt5_test/` — HyperFrames 합성 한 장.
- 배경: MT5 US100. M2 화면을 틀 뚫린 자리(**x81~1839 · y81~999 · 1758×918**)에 맞춰 오른쪽(최근 봉) 기준으로 잘라 넣었다.
- 그 위: `01_납품_차트명가NEW/틀만_완성/B_병풍_틀만.png` · 종목 배지(#EF2767) · 강조 상자(#0D9488) · 로고.
- 렌더 24.6초. 결과 `hf/renders/mt5_test.mp4`.

**되는 것이 확인됐다.** 다만 이번 강조 상자는 **눈대중으로 놓은 것**이다. 제대로 하려면 `get_chart_history` 로 받은 봉 시각·가격을 화면 좌표로 바꿔서 놓아야 한다 — 그러면 "MT5 화면 + 정확한 위치의 우리 표시"가 된다. 그 좌표 변환(봉↔픽셀)은 `list_open_charts` 의 `page_bars`·`scale` 과 캡처한 가격축을 같이 보면 구할 수 있다.

## 5. 남는 판단

- 이 길로 갈 거면 **MT5 창 크기·템플릿을 고정**해 두는 게 먼저다. 창 크기가 바뀌면 뚫린 자리에 맞추는 배율이 매번 달라진다.
- 로고 자리가 RSI 패널과 겹친다. 실제로 쓸 때는 틀 여백(아래 60px)에 놓는 게 맞다.
- MT5 데이터로 **우리 렌더러가 차트를 그리는 길**도 있다(`get_chart_history` → `market` 에 먹이기). 그러면 브랜드 색·세이프에어리어가 우리 규격 그대로다. 화면을 그대로 쓰는 것과 둘 중 무엇을 기준으로 할지는 이정찬 결정이다.
