## 규칙 — 실측

**윈도우는 경로의 *마지막 조각*에서만 끝 공백·마침표를 떼어낸다.** 중간 조각(부모 폴더)에서는
안 떼어낸다. 그래서 폴더는 공백 없이 만들어지는데, 그 폴더를 부모로 쓰는 경로는 공백을 달고
가서 못 찾는다. **만들 때는 조용히 넘어가고 나중에 터진다.**

B 가 2026-09-18 에 잰 결과 (파이썬 3 · PowerShell 5.1, Windows 11):

| 한 일 | 결과 |
|---|---|
| `os.makedirs("끝공백 ")` | 디스크에 `끝공백` — **공백이 떼어졌다** |
| `os.makedirs("끝마침표.")` | 디스크에 `끝마침표` — 마침표도 같다 |
| `New-Item -ItemType Directory 'PS끝공백 '` | 디스크에 `PS끝공백` — PowerShell 도 같다 |
| `os.path.isdir("끝공백 ")` | **True** (거짓 안심 — 마지막 조각이라 떼어내고 본다) |
| `open(os.path.join("끝공백 ", "a.txt"))` | **FileNotFoundError** ← 여기서 터진다 |
| `open("진짜끝공백.txt ")` 뒤 `exists` 양쪽 | 둘 다 True — 파일 이름 끝 공백만이면 해가 없다 |

즉 **"폴더 이름이 공백·마침표로 끝날 때"만 위험하다.** `isdir` 로 확인해 봐야 True 가 나와서
검사로도 안 걸린다.

## 처방 (제안)

경로 조각을 **만들 때** 떼어낸다 — 읽을 때 고치면 이미 어긋난 뒤다.

```python
part = part.strip(" .")          # 폴더·파일 이름 한 조각마다
```

ExtendScript 도 같다: `name = name.replace(/[ .]+$/, "")`.
사람이 지은 이름을 받는 자리(제목·채널 이름·회차 제목)에 붙이면 된다.
