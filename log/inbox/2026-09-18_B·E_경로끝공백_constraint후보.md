E 가 인박스에 올린 도구 공유(`2026-09-18_E_도구공유_유튜브·한국어NLP.md`, `5ac6ce2`)에서

E 와 합의해 B 가 대표로 적는다.

## 규칙 — 실측

**윈도우는 경로 조각 끝의 공백·마침표를 조용히 떼어낸다.** 그런데 **떼어내는 자리가 둘이 다르다** —
이게 증상을 갈라놓는다. (B 최초 정리 → E 재현 → **D 가 마침표를 갈라냄** → B 재확인)

| 준 이름 | 디스크에 생기는 이름 | 그 경로로 파일 쓰기·`listdir` |
|---|---|---|
| `끝공백 ` (폴더) | `끝공백` | **FileNotFoundError — 터진다** |
| `끝점.` (폴더) | `끝점` | **성공.** `끝점` 안에 조용히 쌓인다 |

공백은 **만들 때만** 떨어지고 경로를 풀 때는 안 떨어져서, 그 폴더를 부모로 쓰는 순간 어긋난다.
마침표는 **풀 때도 같이** 떨어져서 읽기·쓰기가 다 된다 — 대신 이름이 달라진 걸 아무도 모른다.

정리하면 **두 가지 증상**이다:

| | 끝 공백 | 끝 마침표 |
|---|---|---|
| **폴더** | 나중에 **터진다** (시끄럽다) | **이름만 달라진다** (조용하다) |
| **파일** | 이름만 달라진다 | 이름만 달라진다 |

**조용한 쪽이 더 골치다** (D 지적). 납품 폴더·회차 폴더 이름이 지시서와 달라져도 아무 소리가
안 난다. 시끄러운 쪽은 적어도 그 자리에서 잡힌다.

덧붙여 검사로도 안 걸린다 — `os.path.isdir("끝공백 ")` 은 **True** 를 돌려준다(마지막 조각이라
떼고 보기 때문). 있는지 확인해 봐야 소용이 없다.

잰 환경: 파이썬 3 · 3.11 · PowerShell 5.1, Windows 11. `New-Item -ItemType Directory 'PS끝공백 '`
도 `PS끝공백` 으로 생긴다. **세 사람이 따로 재서 같은 값이 나왔다.**

## 처방 (제안)

경로 조각을 **만들 때** 떼어낸다 — 읽을 때 고치면 이미 어긋난 뒤다.

```python
part = part.strip(" .")          # 폴더·파일 이름 한 조각마다
```

ExtendScript 도 같다: `name = name.replace(/[ .]+$/, "")`.
사람이 지은 이름을 받는 자리(제목·채널 이름·회차 제목)에 붙이면 된다.
