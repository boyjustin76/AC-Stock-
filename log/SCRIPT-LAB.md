### 1. 포인트_차 실측 기준선 — DB 에 없던 숫자다

`차트명가(숏)` 의 `[포인트_차]` 폴더 43개, 그중 자막(SRT)이 남아 있는 36편 실측.

| 항목 | 값 | 비고 |
|---|---|---|
| 영상 길이 중앙값 | **54.9초** | 최소 37.6 · 최대 116.1 (n=36) |
| 발화 글자수 중앙값 | **384자** | 공백·헤더·지문 제외 |
| 발화 속도 중앙값 | **7.41자/초** | 최근 편 6.5~7.9 |
| 대본 파일 원문 글자수 중앙값 | 659자 | 헤더·지문 포함 (n=43) |

**SL 기준(6.82자/초)과 다르다.** 포인트_차가 더 빠르다 — 포인트는 차트 실연이
적고 말이 이어져서 그렇다. 포인트 편 분량을 SL 기준으로 잡으면 짧게 나온다.

뼈대는 SL 과 같은 4단이되 이름이 다르다:
`① 훅 (Hook)` → `② 근거 (Evidence)` → `③ 본론 (Body)` → `④ 결과/결론 (Conclusion)`.
43편 중 38편이 이 표기를 그대로 쓴다. 나머지는 `(후킹)/(본론)` 또는 `① 도입부/② 본문/③ 결론`.

이름 규칙(43편 전수 일치, `naming_rule` 에 없음):
- 폴더 `YYMMDD_[포인트_차]제목`
- 파일 `[포인트_차]제목.txt`
- (트팩 원본은 `YYMMDD_[포인트]제목` / `[포인트]제목.txt`)

### 2. [포인트_차]가 [포인트]를 카피·변형하는 알고리즘

트팩↔차명 짝 7건을 붙여서 10자 n-gram 겹침을 쟀다. **모드가 두 개로 갈린다.**

| 짝 | 트팩 원본 | 차명 | 간격 | 압축률 | 10자 겹침 |
|---|---|---|---|---|---|
| RSI+MACD | 260227 | 260924 | 7.0개월 | 1.01 | **70.6%** |
| FVG 단타 | 260218 | 260903 | 6.5개월 | 0.94 | **68.9%** |
| 캔들 꼬리 | 260322 | 260910 | 5.6개월 | 0.87 | **59.7%** |
| 구름대 공략 | 251101 | 260808 | 9.2개월 | 1.13 | **47.8%** |
| 골든크로스 | 260728 | 261001 | 2.1개월 | 0.92 | 5.4% |
| 후행스팬 | 260814 | 260810 | ~동시 | 0.87 | 3.0% |
| 왜 상승은 같은 모양 | 260513 | 260528 | 0.5개월 | 0.59 | 1.4% |

**모드를 가르는 건 원본과의 시간 간격이다.**

- **모드 A — 근접 복제 (간격 5.5개월 이상, 겹침 48~71%)**
  본론 문장을 거의 그대로 가져온다. 이 4편은 전부 차명 폴더 안에
  `TF(참고)_<트팩폴더명>` 폴더가 통째로 들어 있다. 카피인 걸 숨기지도 않는다.
- **모드 B — 뼈대만 복제 (간격 2개월 이하, 겹침 1~5%)**
  주제·논리 순서·근거는 같은데 문장은 전부 다시 쓴다. 참고 폴더도 없다.
  겹침 1.4~5.4% 는 저장소가 SL 에 쓰는 기준선(2.2%)과 같은 수준이다.

즉 **"두 채널에 비슷한 영상이 가까운 시점에 같이 나가지 않게" 하는 게 규칙**이다.
묵힌 주제는 복붙하고, 최근 주제는 다시 쓴다.

방향도 폴더가 증언한다 — 참고 폴더가 어느 쪽에 들어 있느냐로 갈린다:
- 차명이 트팩을 베낌 (`TF(참고)_` 가 차명 폴더에): 구름대·FVG·캔들꼬리·RSI+MACD — 전부 묵은 기법 편
- 트팩이 차명을 베낌 (`참고_..._[포인트_차]` 가 트팩 폴더에): 긁히는 것(260708→260811)·후행스팬(260810→260814)·테스타 이평선(260806→260904)
  → 이 셋은 트팩 폴더에 대본 대신 **라이브 질문 브리프**만 있다. 라이브에서 나온 주제는 차명이 먼저 만들고 트팩이 받는다.

### 문장 단위 변형 규칙 — 후행스팬 짝(요청 건) 기준

| 자리 | [포인트] 260814 | [포인트_차] 260810 | 규칙 |
|---|---|---|---|
| 제목 | 세력도 못 속이는 일목균형표 후행스팬 실전 매매법 | (동일) | **제목은 안 건드린다** |
| 훅 | "복잡하기만 했던 일목균형표, 이제 선 하나만 남기고 전부 지우세요." | "오늘은 일목균형표로 단타 타점 잡는법을 알려드릴게요 / 정말 쉬우니 꼭 따라해보세요." | 명령·선언 → **"오늘은 ~ 알려드릴게요" + 쉽다는 안심** |
| 근거 | "26봉 전 차트와 직접 대조해 주는 지표입니다" | "단순하게 요약하자면 / 이 선은 현재 종가를 선으로 그어서 / 왼쪽으로 26캔들 뒤에 그려둔 것입니다" | 한 문장을 **호흡 단위로 쪼개고 풀어 씀** |
| 본론 | "그렇다면 대체 왜 굳이 26일 뒤에 선을 그어두었을까요?" | "그럼 대체 26일 뒤에 왜 선을 그어두었을까요?" | 어순만 바꾼 **동의 치환** |
| 용어 | 휩소 · 확정적으로 · 폭발하는 · 매물대 | (휩소 삭제) · 확실하게 · 전환되는 | **전문어·과장어 한 단계 낮춤** |
| 지문 | (자료 화면: 차트 강조 연출) | (삭제) | 트팩 연출 지문은 안 가져온다 |
| 결론 | "여러분도 차트에 적용해서 꼭 한번 실전에 사용해 보세요." | "여러분도 꼭 한번 사용해보세요. / **그리고 구독을 누르고 더 많은 매매법을 받아보세요**" | **CTA 를 반드시 갈아끼운다** |
| 분량 | 716자 | 605자 (0.85) | 짧아진다 |

다른 짝에서 반복 확인된 것:
1. **CTA 치환이 예외 없다.** 트팩은 `영트모로 입장하세요` / `아래 영상을 클릭하고`(커뮤니티 유도),
   차명은 `저를 구독하고 다음 영상을 기다려주세요` / `저를 팔로우하시고`(구독 유도).
   7편 중 7편이 그렇다. **이것만은 절대 안 가져온다.**
2. **결론에서 답을 뺀다.** 골든크로스는 트팩이 "장기선으로 추세 읽고 나머지 2선으로 크로스"까지
   구체적으로 알려주는데, 차명은 그 대목을 지우고 "어떠한 세팅값으로 사용해야할까요? / 자세한 내용은
   댓글과 아래 영상을 참고해주세요" 로 끝낸다. 왜상승은 아예 연장파동 설명 도중에 끊고
   "지금 비트코인 차트는 몇번째 파동일까요?" 로 넘긴다 → **정보 유보 + 참여 질문**.
3. **제목은 유지하거나 자극을 한 단계 올린다.** `계좌를 녹이는 골든 크로스` → `계좌를 녹이는 골든크로스의 함정`.
4. **트팩이 들고 온 권위·수식은 지운다.** `코인 대회 우승자들이 수익을 쓸어 담을 때 사용하는 FVG` → `FVG 매매법`.
5. **차명은 지문을 대본에 남긴다.** `(차트보며)` · `(*강한 추세 구간 이미지 사용)` ·
   `(**이번 편은 말하듯이 편안한 대화톤으로 녹음 부탁드립니다)` — 녹음 톤 지시까지 대본에 적는다.
6. **차명 화법 고정구** (`차트명가_숏츠 프롬프터 학습용 데이터.txt` 19,742자와 교차 확인):
   `오늘은 ~ 알려드릴게요` / `~인데요` / `만약 ~라면?` (질문으로 끊고 답) /
   `정리하자면 ~ 라는걸 기억해주세요` / `~하시면 됩니다`.

- 원본: `260809_[포인트]진화한 세력들의 악랄한 움직임` (트팩, 88.2초 / 발화 660자)

**모드 B 로 썼다.** 원본이 260809, 이번 편이 260828 이라 간격이 **3주**다.
§2 표에서 5.5개월 이상만 근접 복제였고, 2개월 이하는 전부 다시 쓴 편이다.
같은 회사 두 채널에 3주 간격으로 같은 문장이 나가는 건 기존 어느 편에도 없다.

또 원본은 포인트_차의 4단 뼈대가 아니라 `① 도입부 / ② 본문 / ③ 결론` 3단짜리
**썰·토크형**이고 문체도 반말에 가까운 구어체(`짰잖아요?` `털어먹는` `와리가리`
`말려 죽일 때까지` `던져버린다고요`)다. 차명 43편 중 이 어투를 쓴 편은 없다.
그래서 **4단 뼈대로 다시 끼우고 존댓말로 낮췄다.**

| 발화 글자수 | 406자 | 중앙값 384자 (범위 280~534) | 범위 안 |

길이는 **토크형 5편**(긁히는 것 7.19 · 손절 8.50 · 포지션중독 7.13 · 시장은롱 7.08 · 왜상승 7.27)
의 중앙값으로 쟀다. 기법 편은 차트를 짚느라 더 느려서(후행스팬 6.70 · 캔들꼬리 6.50)
전체 중앙값 7.41 을 그대로 쓰면 토크 편은 짧게 잡힌다.

원본에서 **버린 것**(모드 B 압축 관행대로 곁가지부터 잘랐다):
- 옛날 세력 수법 두 갈래(손절선 깨기 / 재료 띄우기) → 한 갈래로 합침
- `-80% → +10% → -70% → +10%` 수치 나열 → "한 달이든 반년이든" 한 줄로
- 알고리즘 매매 고도화 언급 → 삭제 (차트 공부한 사람이 많아졌다는 쪽만 남김)

원본에서 **살린 것**: 옛날 세력 vs 지금 세력 대비 → 가격 흔들기 → 시간 끌기 →
레버리지 공포 → 스스로 던짐 → 익절·손절 기준. 논리 순서는 원본 그대로다.

결론은 §2-2 관행대로 답을 주지 않고 다음 편으로 넘겼다:
"그렇다면 이 흔들기 속에서 손절 기준은 어떻게 잡아야 할까요?"
→ **다음 포인트_차 주제는 손절 기준**이 된다. 다만 차명에는 이미
`260715_[포인트_차]당신이 손절을 못하는 이유` 가 나갔다. 겹치지 않게 잡으려면
'못하는 이유'가 아니라 '기준을 어디에 두느냐' 쪽으로 가야 한다.

### 4. 팀장 판단이 필요한 것

1. **방영일.** 폴더 날짜를 오늘(260828)로 적어 뒀다. 확정되면 방영일로 바꾸고 `(중간)` 을 뗀다.
2. **어투 수위.** 원본의 세고 거친 맛(`와리가리` `말려 죽일 때까지`)을 차명 톤에 맞춰 상당히
   눌렀다. 차명 43편 중 가장 센 편이 `260725_[포인트_차]포지션 중독`("나중에 큰 일 납니다")
   정도라 그 선에 맞췄다. 더 세게 갈지는 채널 판단이다.
3. **소스.** 트팩 원본 폴더의 `소스+원본` 에 차트 영상·GIF 가 다 있다. 그대로 쓸지,
   차명용으로 다시 딸지 — 모드 A 편들은 참고 폴더째 가져다 썼다.

### 5. tools/shortform.py — 포인트 편에는 그대로 못 쓴다 (고치지 않았음)

| "570자 → 약 84초" | ① `norm()`(38행)이 파일 전문을 센다 — 참고 헤더·URL·녹음 지문·`훅 Hook` 같은 라벨까지 발화로 계산 ② 속도가 SL 값 6.82자/초 고정 | 발화 406자 · 56.5초 |
| "폴더/파일 이름이 회사 규칙에 어긋남" | `naming_rule` 이 SL 전용(`[SL_차XX_#X]`)이다. 포인트 규칙이 DB 에 없다 | 드라이브 43편 전수: `YYMMDD_[포인트_차]제목` / `[포인트_차]제목.txt` |
| "'포인트/포' 표기를 쓰지 않는다" 위반 | 파일명의 `[포인트_차]` 를 자막 문구로 오인 | 포인트 편은 이 표기가 이름 규칙 그 자체다 |

**나간 편으로 검증했다.** 이미 방영된 `260810_[포인트_차]후행스팬` 을 그대로 넣으면
check 는 "401자 → 59초" 라고 하는데 실제 자막은 **53.1초**, `260910_[포인트_차]캔들 꼬리` 는
"334자 → 49초" 인데 실제 **43.1초**다. 나간 편에도 11~14% 길게 나온다.

**도구는 고치지 않았다.** 매뉴얼 §5 에서 `tools/shortform.py` 는 내 영역이지만, 오늘 받은 일은
대본 3편이고 포인트 갈래를 도구에 새로 넣는 건 범위 밖이라 판단했다. 넣을 거라면 필요한 값은 위에 다 있다:
`--kind point` 로 ①발화만 세기(참고 헤더·URL·`(**...)` 지문·라벨 제외) ②cps 7.19(토크)/6.60(기법)
③`YYMMDD_[포인트_차]제목` 이름 규칙 ④'포인트' 표기 검사 해제. **총괄 승인 후에 넣겠다.**

### 6. 이번에 확인한 함정

- 포인트 대본 파일은 **UTF-8 BOM** 이다. BOM 없이 읽으면 첫 줄이 깨진다.
- 짝을 하나만 보면 틀린다. 요청받은 후행스팬 짝(겹침 3.0%)만 봤다면 "차명은 항상 다시 쓴다"로
  결론 냈을 텐데, 7짝을 다 재보니 절반이 겹침 48~71% 였다. 매뉴얼 §4-1 그대로다.
- 후행스팬 짝은 **차명이 원본이고 트팩이 받은 쪽**이다(트팩 폴더에 `참고_260810_[포인트_차]` 가 있다).
  요청 문구는 반대 방향을 전제했는데 실물은 그렇지 않았다. 방향은 참고 폴더가 어디 있는지로 판정했다.
