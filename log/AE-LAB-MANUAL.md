# 애프터이펙트 .aep/.mogrt 실험 매뉴얼 — D 세션용

> 작성: 클라우드 총괄 세션 (2026-08-29). 근거는 `lab/ae/AEP-MOGRT-조사보고.txt`(어도비
> 공식 자료 조사)와 이 저장소의 실측 기록(`log/worklog.db` — 포토샵 COM 완파,
> 프리미어 BridgeTalk M1~M6)이다. 추측으로 쓴 항목은 없다.

## 무엇을 하는 실험인가

지금 클라우드가 mp4/zip 으로 납품하는 숏폼 차트 소스를, **팀장이 직접 이어서
수정할 수 있는 파일(.aep + .mogrt)** 로도 납품할 수 있는지 확인한다.

- 파일럿 대상은 딱 한 장면: **sl-11-4 컷② '손익비' (176프레임 = 5.867초, 1080×1080/30fps)**.
- 구조는 하이브리드다: **차트 바닥은 스틸 PNG**(팀장도 스크린샷 놓고 작업하는
  스타일이라고 사용자가 확인함), **주석(색박스·라인·버튼·텍스트·빗금)은 AE
  네이티브 레이어**로 다시 그린다. 캔들 리빌 모션은 파일럿에서 포기한다 (승인됨).
- .aep 를 클라우드가 직접 쓰는 건 **금지**다. .aep 는 공식 스펙이 없는 RIFX
  바이너리고, 스펙이 "있던" .psd 도 직접 쓰기는 포토샵이 거부했다.
  **파일은 AE 가 쓰게 한다** — 포토샵을 완파한 그 공식이다.
- 이건 실험이고 실패할 수 있다. mp4 납품 경로(`src/render/`)는 그대로 산다.

역할 분담: **D(너, 로컬) = 실험실. 클라우드 = 저장소 관리와 판정.**
.mogrt 는 내부가 zip(definition.json + .aep)이라, 네가 올리면 클라우드가
definition.json 을 열어 노출 컨트롤이 의도대로 박혔는지 판정할 수 있다.

## 3. 대원칙

1. **읽기는 자유, 쓰기는 앱을 통해서.** .aep/.mogrt 를 파이썬으로 직접 쓰거나
   고치는 실험은 금지. (.mogrt 의 zip 을 **열어 읽는** 건 자유 — 검증엔 오히려 필수.)
2. **경로는 검증된 것부터.** 1순위: 프리미어 때 그대로
   `PowerShell → Photoshop.Application(COM) → bridge.jsx → BridgeTalk → AE 타깃`.
   타깃 이름은 짐작하지 말고 포토샵에서 `BridgeTalk.getTargets(null)` 로 열거해
   `aftereffects` 로 시작하는 실제 문자열을 기록해라.
   2순위(폴백): `afterfx.exe -r <경로>.jsx` — AE 창이 뜬 채로 실행된다.
   종료코드는 스크립트가 `app.exitCode` 로 직접 정할 수 있다.
3. **잡 소스를 BridgeTalk 본문에 싣지 마라.** 본문에는 "이 파일을 실행해라"
   한 줄만 — 이스케이프가 한 번 더 풀리며 `\t` 가 글자 t 로 실행된 실측이 있다.
4. **jsx 안에 alert/confirm/모달을 띄우는 코드 금지.** 성패·측정값은 전부
   파일로 써라 (`C:\aelab\log\*.txt`). 위험한 호출 앞에서 로그를 먼저 flush.
5. **검증은 재열기다.** 만든 .aep 는 반드시 새로 열어 dump(컴포지션 수·fps·길이·
   레이어 이름·키프레임 수)를 파일로 뽑고 §5 스펙과 대조한다. "저장 성공 반환값"은
   증거가 아니다 — qe 가 true 주고 아무것도 안 만든 전례가 있다.
6. **exportAsMotionGraphicsTemplate 에는 경로 인자를 반드시 넣어라.**
   경로를 생략하면 대화상자가 뜰 수 있다 → 모달 = 세션 사망 (constraint 25).
   내보내기 전에 `comp.motionGraphicsTemplateName` 을 먼저 지정한다.
7. **하나 성공했다고 일반화하지 마라.** 파일럿은 장면 하나다. 되는 것/안 되는 것
   경계를 기록하는 게 결과물이다.

## 4. 마일스톤

각 마일스톤은 "판정" 을 통과해야 다음으로 간다. 막히면 그 지점을 기록하고 멈춰라.

**A1 — 통신 스모크.**
포토샵 COM 에서 `BridgeTalk.getTargets(null)` 열거 → AE 타깃 확인 → AE 로
"버전 문자열을 `C:\aelab\log\a1.txt` 에 써라" 잡 전송.
판정: 파일이 생기고 안에 `app.version` 이 있다. (AE 가 꺼져 있으면 BridgeTalk 이
띄워 주는지도 기록 — 안 띄우면 사용자에게 AE 를 켜 달라고 한다.)

**A2 — 컴포지션 생성 + .aep 저장 + 재열기 검증.**
```javascript
app.newProject();
var comp = app.project.items.addComp("차11-4_컷2_손익비", 1080, 1080, 1, 176/30, 30);
app.project.save(new File("C:/aelab/pilot.aep"));
```
새 잡으로 `app.open()` 재열기 → 컴포지션 수·이름·폭·높이·fps·duration dump.
판정: 1080×1080 / 30fps / 5.8667s(176f) 정확히.

**A3 — 바닥 스틸 + 주석 레이어 재현.**
- 바닥 스틸은 **이미 저장소에 있다**: `lab/ae/cut2-base-r63-무주석.png`
  (1080×1080, 캔들+20일선만, 주석 없음 — 컷② reveal 63 시점을 클라우드가
  라벨 레이어를 빼고 다시 뽑아 둔 것. 재현 씬은 `lab/ae/cut2-base.scenes.js`).
  이걸 `C:\aelab\base.png` 로 복사해서 쓴다. §2-3 의 mp4 는 A3 판정의
  "눈 대조" 레퍼런스로만 쓴다.
- 주의: 완성 mp4 에서 프레임을 직접 뽑아 바닥으로 쓰지 마라 — 그 프레임엔
  주석이 이미 그려져 있어서 AE 주석과 이중이 된다. 무주석 바닥이 다시 필요하면
  (다른 시점·다른 컷) `log/AE-LAB.md` 에 적어 클라우드에 요청해라.
- 주석 레이어는 §5 표의 수치대로: 셰이프 사각형(익절/손절 색박스), 셰이프
  선(진입 라인·밑줄), 텍스트(라벨·뱃지·놓친 구간), 사선 몇 개(빗금 근사).
  좌표는 스틸 위에서 실측해라 (bar/price 앵커의 픽셀 좌표는 스틸을 자로 잰다).
- 등장 타이밍은 §5 의 in/out 을 불투명도(또는 스케일 팝) 키프레임으로.
  `setValueAtTime` + `setTemporalEaseAtKey`.
판정: 재열기 dump 에 레이어 전부 존재 + 렌더큐로 png 한 장 뽑아
`cut2-early-exit.mp4` 의 같은 시점 프레임과 눈 대조. 스크린샷을 보고에 남긴다.

**A4 — Essential Graphics 노출.**
```javascript
comp.motionGraphicsTemplateName = "차11-4 손익비";
// 각 속성: prop.canAddToMotionGraphicsTemplate(comp) 확인 후
prop.addToMotionGraphicsTemplate(comp);
```
1차 노출 목록 (이만큼이면 "팀장이 수치 하나 건드린다" 충족):
문구 4 (익절 라벨·손절 라벨·`손익비  1 : 2` 뱃지·`놓친 구간`), 색 3 (익절
#14FF36·손절 #9F0000·강조 #E90054). 가격 슬라이더(진입/손절/익절가 → 위치
표현식 연동)는 **2차다** — 파일럿에서 시도하지 마라.
판정: canAdd 가 false 를 주는 속성이 뭔지 목록으로 기록 (이게 실측 가치다).

**A5 — .mogrt 내보내기 + 구조 검증.**
```javascript
var ok = comp.exportAsMotionGraphicsTemplate(true, "C:/aelab/차11-4_손익비.mogrt");
```
판정: 파일 존재 + zip 으로 열어(`Copy-Item → .zip → Expand-Archive`)
definition.json 의 컨트롤 목록이 A4 노출과 일치. 이 mogrt 와 .aep 를 저장소
옆가지로 올리면 클라우드가 2차 판정한다.

**A6 — [사람] 프리미어 실사용 확인.** §2-5. 합격이면 실험 성공 —
팀장 자리 AE 설치를 진행하고, 납품 형태를 「.mogrt(프리미어에서 수치 편집) +
.aep(AE 에서 구조 편집) + 지금의 mp4(보험)」 로 확정한다.

## 6. 함정 (프리미어·포토샵에서 미리 흘린 피)

- 모달 = 조용한 죽음. alert 금지, export 경로 필수, 첫 실행은 사람이 지켜본다.
- BridgeTalk 본문 이스케이프 — 잡은 파일로, 본문은 실행 지시 한 줄.
- 파일 경로는 역슬래시/슬래시 를 앱이 가린다 — ExtendScript `File` 은 URI 표기도
  받으니 실패하면 표기부터 바꿔 본다 (프리미어 sqpreset 은 역슬래시만 받았다).
- "성공 반환값" 은 증거가 아니다 — 재열기 dump 와 파일 존재로만 판정.
- AE 환경설정 파일쓰기 허용(§2-2) 안 켜면 로그 파일이 조용히 안 생긴다 —
  "아무 일도 안 일어남" 의 1순위 용의자다.
- 스크립트로 만든 텍스트 레이어는 `Source Text` 를 TextDocument 로 통째로
  읽어 고쳐서 다시 대입해야 폰트·크기가 박힌다 (속성 개별 대입 아님).
