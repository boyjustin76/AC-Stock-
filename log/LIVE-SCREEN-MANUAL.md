## 무엇을 만드는가

해외선물 유튜브 **차트명가** 생방송 화면을, **팀장이 직접 열어 고칠 수 있는 .ai 한 파일**로

## 0. 시작 전 확인 — 건너뛰지 마라

1. **일러스트레이터가 켜져 있는지, 열린 문서가 있는지 본다.**
   ```powershell
   powershell -NoProfile -Command "try { ([Runtime.InteropServices.Marshal]::GetActiveObject('Illustrator.Application')).Documents.Count } catch { 'Illustrator 안 떠 있음' }"
   ```
   **0 이 아니면 멈춘다.** 이정찬이 직접 열어 둔 문서일 수 있다. 실제로 2026-09-17 에
   아트보드 캔버스 한계로 스크립트가 중단된 뒤 열린 문서를 전부 닫다가 **이정찬이 열어 둔
   원본까지 저장 없이 닫았다.** `run.ps1` 이 이걸 막아 주지만(`-Force` 로만 넘어간다),
   확인용 스크립트를 손으로 돌릴 때는 스스로 봐야 한다.
   꺼져 있는 걸 켜는 건 무해하다 — 위험한 건 남이 쓰는 중인 앱뿐이다.
2. **세션은 자기 worktree 폴더에서 띄운다** — `03_저장소\worktrees\B_Image`.
   저장소 `.claude/`(UTF-8 env·git_guard 훅·radar 스킬)는 세션을 시작한 폴더에서만 읽힌다.
   뜬 뒤 `python -c "import os;print(os.environ.get('PYTHONUTF8'))"` 가 `1` 이면 걸린 것이다
   (runbook 37·38, decision 30).
3. **`brand/EXTENDSCRIPT-TRAPS.md` 를 먼저 읽는다.** 여기 매뉴얼은 그걸 되풀이하지 않고
   번호로 가리킨다.

## 1. 명령

전부 저장소 뿌리에서 돈다. `run.ps1` 은 **공용 실행기** `tools/_com/run.ps1` 로 넘기는 껍데기다
(2026-09-21, next_step 46 2단계). AE·프리미어·포토샵도 같은 것을 쓴다 — 고칠 일이 생기면 거기서 고친다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "tools/illustrator/run.ps1" <이름>
```

| 이름 | 무엇 | 걸리는 시간 |
|---|---|---|
| `build_live` | **본 작업.** 아트보드 10장을 짓고 저장, 미리보기 png 10장 | 10분 안팎 |
| `build_rollad` | 롤링광고 배너 11장을 .ai 로 | 몇 분 |
| `dump_ai` | 원본 .ai 구조 읽기 (아트보드·레이어·글꼴·색). 읽기만 한다 | 원본 여는 데 시간 |
| `dump_caps` | 원본 안 캡쳐(래스터) 후보의 자리를 잰다 | 〃 |
| `dump_board` | 아트보드 하나를 항목 단위로 떠서 적는다 — **사용자 수정판과 내 판을 값으로 비교**할 때 | 〃 |

`-Force` 는 남의 문서가 열려 있어도 진행한다. **웬만하면 쓰지 않는다.**

빌드는 10분쯤 걸리니 백그라운드로 돌리고 기다린다. 결과는 `01_납품_.../라이브화면/build_log.txt`
와 미리보기 png 로 확인한다. **png 를 눈으로 보기 전에는 됐다고 하지 않는다.**

## 4. 구역 좌표 — 손대면 OBS 가 어긋난다

`build_live.jsx` 위쪽 `Z` 하나에 모여 있다. 여기만 고치면 열 장에 다 걸린다.
**바꾸면 납품 `읽어보기.txt` 의 구역표도 같이 고친다.** OBS 소스가 이 자리에 맞춰 놓여 있다.

2026-09-18 기준 (1920x1080, y 는 위에서 아래):

```
광고    y    0~138   전폭
정보 띠 y  140~218   x 0~1519      |  시계   y 140~218  x 1521~1903
차트    y  220~1063  x 17~1519     |  포지션 헤더 221~247
                                   |  종류/거래량·수익 248~394

```

**오른쪽 맨 아래는 캠 자리다.** 처음에는 트팩 판을 그대로 옮기느라 패널을 아래까지 꽉 채워
캠이 들어갈 데가 없었다 (2026-09-18 이정찬 지적).

기준은 **`더원트레이더_라이브화면_실제.png`(방송 갈무리)** 다. 같이 받은 `_틀.png` 는
설계도인데 **캠이 실제보다 작다** — 실제 쪽을 따른다 (이정찬 판단). 실제의 캠은 화면 높이의
**26.3%** 이고 맨 아래까지 내려온다. 우리는 병풍 안쪽 1063 에서 멈춘다 (그 아래 17px 은 테두리).

포지션표만 실제 비율보다 조금 크다 — 우리 캡쳐가 트팩 것보다 줄이 많아서(머리글 + buy/sell
두 줄 + 합계) 실제 비율로 줄이면 합계 줄이 잘린다.

## 5. 캡쳐는 우리가 그리지 않는다

차트·포지션표·수익요약·댓글창·시계·카드는 **트팩 원본 .ai 에서 항목째 복사**한다. 차트명가도
같은 프로그램(MT5·유튜브 댓글)을 쓰기 때문이다 (2026-09-16 이정찬).

**참고용 PNG 를 줄여서 자르지 마라** (TRAPS ⑳) — 압축 + 축소로 두 번 열화된다. 원본 .ai 안에
같은 그림이 원해상도 래스터로 들어 있다. 자리는 `dump_caps.jsx` 로 잰 값이 `CAPS` 에 있다.

칸에 넣는 방법이 셋이다. **칸을 줄였는데 `capFill` 을 쓰면 표가 세로로 눌린다.**

| 함수 | 무엇 | 쓰는 데 |
|---|---|---|
| `cap(..., "fit")` | 비율 그대로 칸 안에 | 시계 |
| `capFill` | 비율 무시하고 칸을 꽉 채움 | 스티커 메모 |
| `capCrop` | 가로폭만 맞추고 칸 밖을 **자름** | 포지션표(아래 흰 여백을 자른다) · 댓글창(`"bottom"` — 위의 오래된 줄을 자른다) |

댓글창을 아래에서 자르면 마지막 줄이 반 토막 난다. 채팅은 오래된 줄이 위로 밀려 나가는
것이므로 위를 자르는 게 맞다.

## 6. 글자 앉히기 — px 가 아니라 비율로

트팩은 프리텐다드, 우리는 **궁서(Gungsuh)** 다. 같은 pt 라도 글자가 차지하는 높이가 달라서
**pt 를 그대로 옮기면 안 맞는다.** 09·10 을 처음에 px 로 옮겼다가 이정찬에게 반려당했다 —
*"원본과 비교하면서 격자 및 비율 단위로 따라해. px 단위가 아니라."*

그래서 `inkSet` 을 쓴다: 글자를 윤곽으로 떠서 **잉크 높이 ÷ 칸 높이** 비율을 맞추고, 같은 줄
묶음은 한 크기로 준다. 포토샵 썸네일에도 쓸 수 있는 방법이다.

관련 함정: 텍스트 프레임의 `top`/`left` 는 글자가 실제 차지하는 자리가 아니다 (TRAPS ⑫).
크기를 바꾼 직후의 `geometricBounds` 는 갱신 전일 수 있다 (⑬).

## 7. 자주 밟는 함정 (자세한 건 TRAPS 로)

- **CS6 로 저장하면 사람이 열 때마다 창이 뜬다** → `Compatibility.ILLUSTRATOR24` (⑨-2).
  한 번 이것 때문에 COM 이 300초 멈췄고, 뒤에 남은 창이 파일을 잡아 `saveAs` 가 실패했다.
- **남의 원본을 열 때 끊긴 링크 창이 뜨면 멈춘다** (⑨-3) → `openRef()` 가 여는 동안만
  알림을 끈다. **사람이 볼 창을 확인할 때는 알림을 켠 채로 열고 화면을 캡처해서 본다.**
- **문서 사이로 복사한 래스터에 `.width`/`.height` 를 박으면 멈춘다** (⑰) → `resize()` 만 쓴다.
  이걸로 두 번, 9분 넘게 굳었다.
- **PNG 내보내기는 `transparency` 만으로 부족하다 — `matte = false`** (⑮).
- **캔버스는 원점에서 ±8172pt** (⑭) → 아트보드를 세로로 쌓고 `X0` 를 음수로 민다.
- **`pdfCompatible = false` 로 저장하면 PDF 오류 모달이 떠 COM 이 멈춘다** (⑨-4). 파일이 커져도 끄지 마라.
- **모달 내용은 `PrintWindow` 로 떠서 읽는다** (⑨-5). 화면 캡처는 다른 창에 가리면 헛장을 찍고,
  UIA 는 어도비 자작 창 속을 못 읽는다. 모달인지는 메인 창의 `IsWindowEnabled = False` 로 본다.
- **경로 조각 끝의 공백·마침표** → `safeName()`, **constraint_note 56**. 폴더면 터지고 파일이면
  이름이 조용히 달라진다. 일러스트레이터도 같다(2026-09-21 실측) — 부모 폴더 끝이 공백이면
  `saveAs` 가 **`오류: the operation was cancelled`** 로 실패한다. 폴더가 없다는 말이 아니라서
  이 문구만 보고는 원인을 못 찾는다.
- **한글이 깨지면** 파이썬에 `PYTHONUTF8=1`. worktree 폴더에서 세션을 띄웠으면 저장소
  `.claude/settings.json` 이 걸려서 안 붙여도 된다.

## 8. 손대면 안 되는 것

- **트팩 원본 `260114_라이브화면구성(2026v).ai` 는 절대 저장하지 않는다.** 읽기 전용으로만 연다.
- **이정찬이 열어 둔 문서는 건드리지 않는다.** 닫지도 않는다.
- **롤링광고 원본은 `롤링광고_사용자수정.ai` 다.** `roll_ad.py` 로 납품 폴더에 다시 그리면
  이정찬이 손으로 한 수정이 사라진다.
- **D 파일(`tools/style/`)은 고치지 않는다.** 필요하면 D 에게 말한다.
- 강조색 `#EF2767`, 한지 `#F3EEE3` 은 이정찬이 정한 값이다. 짐작으로 바꾸지 않는다.
- 기존 브랜드 글꼴(GmarketSans·S-Core Dream)은 이 판에 쓰지 않는다 — **궁서**다.
