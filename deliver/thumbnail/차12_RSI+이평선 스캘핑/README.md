## 차트는 본편과 같은 시장이다

세 안 모두 본편 씬(`scenes/cmg12-*.scenes.js`)이 쓰는 seed 를 그대로 가져왔다.
썸네일에서 본 장면이 영상 안에 그대로 나온다.

- A = `cmg12-buy` (seed 161, 1분) — 진입 53봉·러너
- B = `cmg12-fail` 컷13 (seed 96) — 교차 10회 중 다섯 곳
- C = `cmg12-fail` 컷14 (seed 25) — RSI 70 돌파 후 45봉 유지

썸네일용 씬은 `scenes/thumb-ch12-A·B·C.scenes.js`.

## .psd 가 필요하면

**png 만 넣어 뒀다.** 회차당 .psd 가 12MB 라 여섯 개면 72MB 다 — 저장소가 감당할 크기가 아니다.
고른 안의 .psd 는 명령 한 줄로 다시 나온다 (안 하나에 1~2분).

```bash
node src/cli.mjs --config scenes/thumb-ch12-A.scenes.js --all --stills 1
```

차트 png 를 `config.json` 의 `chartDir` 로 복사하고 이름을 맞춘 뒤,

```powershell
.\tools\photoshop\run.ps1 build_thumb
```

`tools/photoshop/config.json` 의 `build` 에 뽑을 id 만 적으면 그것만 만든다.
포토샵과 템플릿 `.psd` 가 있는 PC 에서만 된다.
