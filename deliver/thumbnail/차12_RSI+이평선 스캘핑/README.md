## 타이틀 크기 — 격자박스에 맞췄다 (2026-09-03)

1차 시안은 좌상단 타이틀이 너무 컸다. 규격은 지킨 것이었다 — 열 회차 완성본에서 잰
고정 높이(윗줄 141px · 아랫줄 194px, `thumbnail_rule` 4·5)를 그대로 썼다. 문제는 그게
**수치**라는 것이다. 차12 는 문구가 길어 같은 높이인데 아랫줄 폭이 1488px 까지 나갔고
익절 태그와 붙었다.

그래서 크기를 손으로 정하는 대신 **상자**를 정했다 (`thumbnail_rule` 28).

| | 값 |
|---|---|
| 좌상단 타이틀 상자 | `(75,100)~(1306,394)` — 오른쪽 1306 은 열 회차 윗줄 관측 최대폭 |
| 이번 배율 | **x0.827 (17% 축소)** — 아랫줄 1488px 가 상자 폭 1231 을 넘어서 |
| 결과 | 세 안 다 아랫줄 `(75,225,1313,394)` 로 같은 자리에 들어갔다 |

넓은 줄 하나가 배율을 정하고 두 줄에 똑같이 걸린다 — 줄마다 따로 줄이면 윗줄·아랫줄
크기 비가 회차마다 달라진다. **상자를 안 넘는 회차는 안 줄어든다** (확대는 절대 안 한다).
짧은 문구는 예전 회차와 똑같은 크기로 남는다.

구현은 `tools/photoshop/config.json` 의 `titleBox` + `build_thumb.jsx`.
영상 고정 양식에도 같은 방식의 상자가 있다 — `brand/STYLE.md` 2장 (`thumbnail_rule` 29).

## .psd 가 필요하면

**png 만 넣어 뒀다.** 회차당 .psd 가 12MB 라 여섯 개면 72MB 다 — 저장소가 감당할 크기가 아니다.
고른 안의 .psd 는 명령 한 줄로 다시 나온다 (안 하나에 1~2분).

```bash
node src/cli.mjs --config scenes/thumb-ch12-A.scenes.js --all --stills 1
```

차트 png 를 `config.json` 의 `chartDir` 로 복사하고 이름을 맞춘 뒤,

```powershell
.\tools\photoshop\run.ps1 build_thumb
```

`tools/photoshop/config.json` 의 `build` 에 뽑을 id 만 적으면 그것만 만든다.
포토샵과 템플릿 `.psd` 가 있는 PC 에서만 된다.

## 참고

- 이 회차의 안들은 셋 다 시장(seed)이 달라 `scene`/`tags` 를 안 달았다.
  컨테이너 대체 경로(`tools/thumbnail_png.py`)로는 못 뽑는다 — `config.json` 의 `_scene` 참고.
  그 경로는 `titleBox` 도 안 읽는다(폭 역산 방식 그대로다) — 고칠 때 같이 봐야 한다.
- 차트는 타이틀이 1563 까지 나가던 때 기준으로 그렸다. 지금은 상자가 1306 에서 끝나
  오른쪽 태그(익절·손절) 자리에 여유가 생겼다 — 캔들을 조금 더 위로 올려 흰 여백을
  줄일 수 있다. 안이 정해지면 그 안만 손보는 게 낫다.
- 인물은 넣지 않았다. 지표가 주제인 회차다 (규칙 19 — #9·#6 과 같은 판단).
