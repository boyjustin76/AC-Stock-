기준(목표 문체) = **8차 + 이정찬 수정**(`차12_더블 볼린저밴드 매매법_8차_이정찬_피드백.docx`에서 취소선을 뺀 글).

## 0. 이정찬 8차 수정에서 읽은 것 (22곳)

범례: 취소선 = 지움 · 빨강(취소선 없음) = 대신 쓴 말 · 초록 = 더함

| 꼴 | 예 |
|---|---|
| **말 짝(연어)** | 손익비가 나빠지다 → **낮아지다** · 규칙이 짧다 → **조건이 적다** · 알아보기 어렵다 → **복잡하다** |
| **`명사+입니다` → 동사** | 구간입니다 → 구간**에서 합니다** · 필터예요. 장치는 아닙니다 → **줄여줄 뿐, 보장해주진 않습니다** |
| **너무 가벼운 말투는 되돌림** | 아니거든요 → **아닙니다** · 문두 **"하지만"을 오히려 더함** |
| **이어서 호흡** | **그러다** … 이탈한 가격**이 나오면, 거기가** 매수 타점입니다 |
| **팀장 예시도 다듬음** | 여기서 진입합니까? → 여기서 진입**하면 될까요?** |
| **비교를 문장 안에** | **밴드를 하나만 켰을 때는** 신호가 자주 나오고 … |
| **용어 구체화** | 손절 → 손절 **라인** |

> **Claude가 8차에서 수치로 밀어붙인 "대화형"이 과했다.** 이정찬이 몇 곳을 합쇼체로 되돌리고 "하지만"을 살렸다.
> 수치 목표를 Claude가 스스로 정한 것 자체가 잘못이었다 — 목표는 사람 판정(쌍)에서 나와야 한다.
>
> **확인 필요** — 80문단 `…같이 이탈하는지 ~~봅니다. 봐야합니다.~~` 는 둘 다 지워져 서술어가 없다. 81문단("그러다 …")과 한 문장으로 잇는 뜻인지 확인.

이 22쌍은 `05_대본자료/팀장쌍/pairs.jsonl` 에 `누가: 이정찬` 으로 쌓았다(쌍 보관소 전체 88개).

**읽기**
- **말투의 뼈대(어미 비율·리듬·화면 가리킴)는 자사 트레이딩팩토리 영상과 가장 닮았다.** 팀장이 원하는 것이 "회사가 이미 하던 말투"일 가능성이 높다.
- **대화의 결(질문·`입니다` 적게·이어 말하기)은 김직선**이 가장 가깝다.
- **확인형 `-죠`는 차트슈타인, 비교는 골드핑거.**
- **질문은 어느 채널도 목표(2.7)에 못 미친다** — 이정찬 수정 뒤에도 8차는 업계보다 질문이 많다. 줄일 여지가 있다.
- 한계: 목표는 **쓴 대본**, 채널들은 **말한 자막**이다. 말은 원래 이어 주는 어미가 많고 `입니다`가 적다. 채널당 3~4편이다.

## 2. 도구 · MCP — 시험한 것과 시험할 것

### 2-1. 이미 시험했다 — 실격 (자를 먼저 검증)

같은 22쌍(8차 ↔ 이정찬)에 대고 "이정찬이 고른 쪽을 더 자연스럽다고 치는가"를 쟀다. 우연 = 50%.

| 자 | 결과 | 판정 |
|---|---|---|
| Kiwi 형태소 언어모델 (`kiwipiepy` 0.23) | 11/22 = 50% | 실격 |
| HyperCLOVA X SEED 0.5B 퍼플렉서티 (네이버 공개 모델, 이 PC에서 돌림) | 12~13/22 = 55~59% (p=0.26~0.42) | 실격 |
| 같은 모델 + **대본 문체를 먼저 읽힘**(더원 방송본 / 김직선 자막 앞에 깔기) | 11/22 = 50% | 실격 |

**결론 — "작은 일반 모델의 확률 점수"로는 이정찬·팀장의 자연스러움을 못 잰다.**
말로 풀어 쓴 문장(`보장해주진 않습니다`)을 드물다는 이유로 낮게 친다. 자연스러움이 분야마다 다르다는 이정찬의 말이 숫자로 확인됐다.

### 2-2. 가능성이 보였다 — 분야 말뭉치의 말 짝 빈도

회사 Pool 173편 + 자막 53편에서 두 표현의 빈도를 셌다.

| 8차 ↔ 이정찬 | Pool | 자막 |
|---|---|---|
| 알아보기 어려 ↔ **복잡해** | 0 : 7 | 0 : 4 |
| 손절을 어디 ↔ **손절 라인** | 0 : 49 | 0 : 31 |
| 아니거든요 ↔ **아닙니다** | 0 : 100 | 2 : 37 |
| 손익비가 나빠 ↔ 손익비가 낮아 | 0 : 0 | 0 : 0 |
| 규칙이 짧 ↔ 조건이 적 | 0 : 0 | 0 : 0 |

**자료가 있는 곳에서는 전부 이정찬 쪽.** 다만 10쌍 중 5쌍은 예가 없다 — **말뭉치가 작다.**
(참고: Pool 에는 "손익비가 좋" 5 : "손익비가 높" 2 — `나빠지다 → 낮아지다` 는 우리 자료로는 뒷받침되지 않는다.)

→ **분야 말뭉치를 키우는 것**이 가장 확실한 다음 수다.

| 도구 | 하는 일 | 필요한 것 | 누가 |
|---|---|---|---|
| **yt-dlp 자막 대량 수집** (이미 있음) | 트레이딩·교육 유튜버 수백 편 자막 → 말 짝 빈도 사전 | 채널 목록 | Claude |
| **모두의 말뭉치 구어** (국립국어원) | 실제 한국어 구어 대규모 | 사이트 신청·승인 | **이정찬** |

## 3. 가장 가까운 공식

| 공식 | 무엇을 재나 | 팀장 말과의 연결 | 주의 |
|---|---|---|---|
| **종결어미 엔트로피** H = −Σ p(어미) log p(어미) · **반복 확률** P(같은 어미 \| 앞 어미) | 어미가 얼마나 고르게 섞이는가 | "종결어미의 단조로움", "'입니다' 너무 자주" | 지금 쓰는 "`-니다` 연달아"가 이것의 거친 판 |
| **nPVI** (Grabe & Low 2002) = 100/(m−1) · Σ \|dₖ−dₖ₊₁\| / ((dₖ+dₖ₊₁)/2) | 이웃한 두 단위 길이 차이의 평균 — 말의 리듬 | "리듬감 없음", "늘어지는 호흡" | 원래 모음 길이용. 문장 길이 또는 **TTS 음성 길이**에 적용 |
| **놀람(surprisal)과 정보 밀도 균일성(UID)** (Meister 외 2021) | 문장 속 정보가 고르게 퍼지는가. 고르지 않을수록 수용도가 낮다 | "술술 안 읽힌다" | **분야에 맞는 언어모델이 있어야 한다** — 2-1에서 작은 일반 모델은 실패 |
| **PMI / 로그우도비** | 두 낱말이 얼마나 붙어 다니나(말 짝) | 손익비가 **낮아지다**, 조건이 **적다** | 큰 분야 말뭉치 필요(2-2) |
| **Bradley–Terry 모형** P(A가 B보다 낫다) = e^{sA} / (e^{sA}+e^{sB}) | 쌍 판정 → 문장 점수 | **팀장·이정찬이 고른 쌍을 "팀장 점수"로 바꾸는 식**. 선호 학습의 바탕 | 쌍이 수백 개 필요. 지금 88개 |

> "자연스러움"을 한 숫자로 재는 공식은 없다. 위 다섯 개를 **축**으로 두고, 어느 축이 팀장 판정과 맞는지를
> 쌍에 대고 고르는 것이 정석이다(Bradley–Terry 로 묶는 것이 그 마지막 단계).
